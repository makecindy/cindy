# 模型选择器体验插件

由 Forge plain 模板生成的本地测试插件，无网络、文件或模型调用权限。
需要包含本次 `cindyUI.pickModel` 改动的 Desktop 开发构建，重启后加载新增 preload。
`minCindyVersion` 只标识基础插件形态；新接口尚未发布，页面通过函数检查明确提示旧宿主。

用 `ghost_forge_pack` 打包本目录，手动导入生成的 `.cindy` 文件后，打开「模型选择器体验」
侧栏页签或一级主视图。首次安装走 Cindy 的正常确认流程。

- 点击「选择模型」：宿主模型面板贴按钮展开，选择后立即显示完整结果。
- 对照聊天输入框：检查供应商、搜索、收藏、最近使用、说明与引擎／推理强度／Fast。
- 选择其他电脑或分享模型：结果应带完整 `agentDeviceId`，不能丢来源。
- 点击「对比旧弹窗」：原有 `/model-picker` 居中确认流程仍可使用。
- 页面底部按钮、窄侧栏、弹出独立窗口、缩放与 Light / Dark 分别体验。
- Esc／点击外部取消；页面滚动、导航或关闭会撤销，原选择保留。

选择配置只存在本次页面内存里；不发送消息、不创建任务、不调用付费模型。
收藏与参数编辑沿用插件选择器的临时草稿，不改宿主偏好。
