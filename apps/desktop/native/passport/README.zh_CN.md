# Cindy Passport 蓝牙

## 什么是 AI Passport？

[AI Passport](https://ai-passport.folotoy.cn) 是 FoloToy 的开源随身设备，带有屏幕、按键、麦克风和扬声器，可以安装不同社区固件。此配套功能让它成为 Cindy 的任务阅读与语音回复设备。

- [独立 Cindy 固件与下载](https://github.com/lengjingxu/cindy-passport)
- [AI Passport 官方社区](https://ai-passport.folotoy.cn)
- [AI Passport 官方硬件与源码](https://github.com/FoloToy/ai-passport)

## 连接 Cindy


配套 ESP32-C3 固件连接 macOS Cindy。在设置 → 快捷键 → 配件 → Cindy Passport 中启用，选择发现的设备；macOS 请求时输入设备显示的配对码。菜单栏控制仍可使用。需要蓝牙权限，默认关闭。按账号隔离的 `passport-settings.json` 只保存显式覆盖，恢复默认会删除覆盖；开发环境的 `CINDY_PASSPORT_BLE=1` 设置开发默认值。其他系统显示不支持。

开发使用正式的隔离启动入口：

```sh
pnpm restart:desktop:remote --region=global --isolated=@worktree
```

开发需要 Xcode 命令行工具，打包客户端包含 Swift helper。选择的设备 ID 在 UserDefaults 中按 profile 与数据账号隔离；断开会取消自动连接，不删除 macOS/NimBLE 配对密钥。不会切换到 Wi-Fi 或 HTTP。

正式本机任务目录过滤归档及工作子任务。最多 8 个任务，依次优先等待、错误、运行、完成。已观察的完成/错误状态在活动提示清空后保留于内存，最多 100 条；适配器停止时清空。活动任务可能占满 8 个位置，不复刻远程镜像任务和侧栏顺序。

任务列表显示状态。上下键选择任务，确认键进入详情；详情中上下键翻页阅读 Cindy 的最新可见回复，确认键开始语音回复，再按确认停止并转写。转写后设备显示文字：上键丢弃并重录，下键循环翻页，确认键发送到原任务。长按确认退出并取消尚未确认的录音。

音频使用 16 kHz 单声道、固定 16 kbit/s Opus 和 40 ms 分帧。完整音频在内存中解码为 PCM，复用 Cindy 当前选择的语音服务和识别模型。Cindy 内置语音与用户显式配置的供应商沿用各自已有凭据与连接方式；切换配置或账号会中止录音，Passport 不自行改选模型。

主进程只向原本机任务放行硬件确认后的文字。渲染器通过 Cindy 原有输入队列提交，不替换用户已有的草稿，并回报是否接受。每次确认只能领取一次；Cindy 在 15 秒内未领取时回到预览。离开页面只清除设备侧跟踪，不撤销已经领取的消息。发送被拒后回到硬件预览，需重新确认；断连会使待确认结果失效。不记录原始音频或转写文字。任务回复遵守清空和回溯的可见性边界，并通过已有固定长度快照分页下发。

服务 `C1DC0001-51C4-499D-A186-4621A4938301`：认证 RX `8302`、认证读取/通知 TX `8303`、录音 indication `8304`。任务协议仍为 v1：uint16LE 长度、版本、数量、40/80/16/192 字节 NUL 填充 UTF-8 字段。录音 v1：kind:u8、token:u32LE、sequence:u16LE；开始=1（40 字节任务 ID）、音频=2（1–120 字节编码数据）、结束=3、取消=4。序号从 0 开始，每个音频帧递增，结束/取消使用下一个序号。最多 752 帧、45 秒耗时，包含固件编码器尾部静音。录音需要两端支持，旧固件仍支持任务快照。

Ogg Opus 时间轴固定使用 48 kHz 时钟：每个 40 ms 包增加 1,920 个采样，与 16 kHz 输入采样率无关。修改主进程语音代码后，必须通过开发启动包装器重启电脑端；渲染器热更新不会替换运行中的包校验器。

主机测试及编译不能证明实物录音质量、无 PSRAM 的内存余量、权限、重连或中文显示质量。需要更新固件后人工验收，构建不会自动刷机。

设备控制使用 TX 通知：`version=2:u8, action:u8, taskId:40 bytes, recordingToken:u32LE`（共 46 字节，ATT MTU 至少 49）。动作 1–6 分别为进入、上一页、下一页、重录、确认和取消。预览操作必须匹配任务和录音标识。快照状态以 `draft:<8位十六进制标识>` 表示待确认，`retry:<标识>` 表示发送被拒，`asr:<标识>` 表示正在转写，`error:<标识>` 表示转写失败。设备不会显示标识。回复页使用 `[页码/总页数]` 和三行短文本。固件与电脑端须一起更新。
