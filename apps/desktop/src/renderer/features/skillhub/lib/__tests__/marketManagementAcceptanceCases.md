# SkillHub 我的发布云端管理验收用例

本文件不是 Vitest 用例，是客户端点测清单。每个用户能访问的入口都要覆盖。

## 市场列表范围

1. 进入 `Skill Hub` 默认在 `可获取`，别人未安装或有更新的 skill 显示 `Clone`。
2. `可获取` 不显示自己的发布物，不显示 `管理`。
3. `全部` 可以看到自己的公开发布物，但仍显示普通浏览/Clone 行为，不显示 `管理`。
4. `我的发布` 显示自己的云端发布物，卡片主按钮为 `管理`。
5. 可见性标签对齐 SkillHub：公开显示 `公开`、团队可见显示 `团队`、私有显示 `私有`（私有只在我的发布云端管理语境中显示）。
6. 正常已发布/审核通过不显示审核状态 tag；只显示 `机审中`、`人工复核中`、`审核未通过`。
7. 从云端详情或编辑页返回时，必须回到原来源 tab；从 `我的发布` 进入就回到 `我的发布`，不能回到默认 `可获取`。

## 市场预览与云端详情页

1. 市场卡片点击后打开半屏云端预览，不跳转到本地 skill 详情页。
2. 半屏预览和云端详情都显示云端 FILES 目录，可点 `SKILL.md`、子目录文件并预览内容。
3. 从 `我的发布` 点击卡片本体打开详情浮窗，不进入 `/skillhub/market/:name`。
4. 顶部展示当前云端版本、归属和市场可见性。
5. 本人云端详情动作统一收口为：编辑信息、管理可见性、Clone、删除。
6. `管理可见性` 打开弹窗回显当前可见团队/部门；保存后走 `set-visibility(shared + visibleSlugs)`，归属变更也在这个弹窗内处理。
7. 非本人云端详情只显示 `Clone`，不显示 `市场管理`。

## 管理动作成功体验

1. 编辑市场信息只改显示名、描述、分类，描述上限 2000 个 Unicode 字符；保存后返回详情并刷新标题/描述/分类。
2. 上架、下架、归属调整、删除都通过 `管理可见性` 或二次确认说明完成。
3. 成功后列表和详情状态刷新，不跳到本地详情页，不丢失当前 Skill Hub 导航上下文。
4. Clone 完成后本地扫描刷新，但不改变云端发布物管理状态。

## 管理动作失败体验

1. 表单校验失败不发请求，用户输入保留，错误显示在表单内。
2. Hub 4xx/5xx 不显示原始 `PATCH /api/s2s...` 技术报错，显示可行动的中文错误。
3. 接口失败后不关闭确认弹窗或编辑页，用户可以重试或取消。
4. 删除失败不从列表移除该 skill。
5. 任何动作失败都不能跳转到本地 skill 详情页。
6. 当前配套 Hub 若尚未提供 S2S 管理写接口，xdt 侧必须停留在当前云端页面并提示“Hub 管理接口暂未就绪，请稍后再试”。

## 非本轮范围保护

1. 本地 skill 详情页不新增云端管理按钮。
2. 本地 skill 详情页不新增删除云端发布物、下架、转团队入口。
3. 普通市场浏览页不新增 `管理`。
