# 原创方法参考

搜索量、难度、排名、点击和被引用次数都只能来自用户提供或实际读取的数据，缺失就写未知，不估算，也不用相近词推断。意图分组是规则标签，只供整理，不是用户行为证据；疑似重叠只说明文字相近，不能证明已被覆盖。任务书交给写作者的是读者、目标、结构和证据需求，不是成文。周报要写明数据来源、时间范围和与上次的差异；差异不等于因果。AI问答问题地图记录的是观察到的提问，不是各平台真实问法的分布。选题板是各选题状态的唯一来源，需要时在 Cindy 中给出，或导出为用户选择的本地文件。

这是通用参考，不包含你的仓库、客户、团队、账号、个人偏好或公司政策。记忆关闭时不导入；不能写入USER.md冒充已知用户事实。
