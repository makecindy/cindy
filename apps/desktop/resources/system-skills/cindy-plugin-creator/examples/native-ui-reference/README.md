# 原生 UI 最小示例

演示现有 `cindy` 上的贡献注册、读取、动作与失效通知；不默认安装。
选择格式后，`preview` 工具读取同一任务的值并返回文本。
支持 `session.statusbar` 时，原底栏同时显示格式，点击可切换；内容和动作仍由插件实现。
底栏高度沿原行、宽度使用剩余空间；没有贡献时不新增占位，也不会打开面板。
示例值仅保存在插件运行时内存，重启后恢复默认；真实配置界面、持久化和业务提交由插件自己实现。
这里不提供配置页面、写入队列、事务或恢复框架，也不要求插件采用特定状态管理方式。

支持 `tabViews` 时，任务标题处的“打开构建日志”和消息旁的“打开结果预览”分别打开两个命名页签。
页面显示收到的定位值，并各自提供可点击的计数示例；再次打开复用原页签并更新定位。
可沿原页签布局并排查看、调整大小、关闭或弹出；没有新边缘区域。定位值不持久化，业务数据仍由插件管理。
页面脚本使用包内 `.js` 文件加载，符合原有 CSP。示例只展示注册、挂载、定位和独立交互；
具体页面内容、功能和数据来源由插件决定，资源访问沿现有授权与隔离规则。

`ui` 是可选增强。`minCindyVersion: 0.1.64` 对应 Manifest v3 的首个正式版本，
不表示该版本支持新增 UI。没有 `cindy.ui` 或相应位置时跳过增强，原工具仍可使用。
此新增接口尚未发布，发布后再登记真实支持版本。

作者类型入口为 `@cindy/maker-shared/plugin-ui`；插件运行时直接使用注入的 `cindy`，
无需 SDK、helper、外网账号或第三方依赖。沿现有 Forge 打包并更新选定的隔离开发实例。
