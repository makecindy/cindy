## 测试条件修正与限制

- Electron 不提供本次尝试的 `Browser.getWindowForTarget` 调试方法，改用 Win32 `SetWindowPos`。这是真实窗口重排测试，但没有覆盖系统拖拽期间的模态 sizing loop。
- CUA 背景拖动被阻止；前景两次报告输入已发送，但尺寸没有改变。通过 `WindowFromPoint` 与前景句柄确认输入命中了 Windows 锁屏。没有解锁、修改系统设置或绕过锁屏。
- 定位脚本最初依赖已满的 resource timing 缓冲区寻找模块，改为使用 dev 实际导入 URL。首次无障碍全挂载模式下固定 2.2 秒等待未等到目标，原失败日志保留；最终使用 5 秒有界观察，保留真实首次出现和稳定时间，目标可见及稳定的断言没有移除。
- CDP 截图的透明侧栏可能显为黑底；本轮 UI 目检使用 `PrintWindow` 原生截图，浅深色文件列表、卡片及文件树均检查。rAF 几何采样和关键截图不能证明物理显示器每个刷新帧都无闪动。
- 本轮是完整 dev 冒烟，不是再次执行所有业务操作或全量单测；沿用最终进度修复后的 49 项定向单测、300 次 Electron 探针与类型检查记录。旧版全量测试的版本边界见 `FOCUS-SCROLL-FIX.md`。
