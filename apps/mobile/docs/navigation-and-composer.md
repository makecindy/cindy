# 移动端导航与新建输入框

移动端以侧边栏抽屉为主导航（左上菜单：任务 / 伙伴切换、搜索、设备管理、设置、切换账号、退出登录），
首页右下角保留悬浮新建按钮。按钮与输入框药丸同为 55pt（`composerGeometry.pillHeight`），坐在输入框
静止底线上：右缘 = 输入框右内边距 16pt，下缘 = 安全区 + 8pt。形变弹簧与时长登记在
`docs/design-rules/DESIGN.md §14.4`。

## 当前交互（iOS）

- 新建：原生 `CindyComposerMorphSource`（`modules/cindy-composer-morph`）接管按钮触摸，按下即横向拉长成等高药丸（不播系统按压），
  iOS 式利落弹簧（响应约 0.36s、刚度 305、阻尼比 0.67，单次过冲约 14pt 后停稳）；抬手进入新建页，滑出松开弹回、不导航。页面挂载前由替身玻璃生长，
  就绪后真实玻璃带速度接力；进入时不播推入动画，进入后恢复普通返回动画。只有首页开启形变。
- 输入框：新建、已有任务、伙伴聊天统一为 55pt 药丸，下沿同一条线；不自动聚焦。手动点药丸先向上
  拉开成完整卡片（原生），约 0.05s 后原生聚焦，键盘随后升起；输入框逐帧跟随键盘
  （均在 `ComposerDockKeyboardFollow.tsx`：新建页 `DockKeyboardBottomSpacer`，已有任务 `DockKeyboardLift` / `DockKeyboardViewportSpacer`）。
- 新建页输入卡固定在页面滚动区之外；已有任务输入卡仅正文与附件可滚动，发送、语音与拖拽把手保留在滚动视口之外。长文本、附件及键盘改变可用高度时仍能直接发送，收起再展开不重挂编辑器。
- 新建任务输入卡内的 `/` 命令和 `@` 资源候选面板使用可收缩的独立滚动视口；键盘弹出时保留输入与发送区域，候选项可在面板内滚动选择。
- 已有任务或恢复草稿的模型后来被关闭时，保留原模型身份与输入内容；模型面板说明需要重选，发送前要求明确选择开启模型，不自动换模型。远程目录仍只传开启模型的详情。
- 减弱动态效果：不播形变与拉开，直接到位。
- 伙伴对话：左上角为返回（回到伙伴列表）；Duo 系统栏已有返回时保留侧栏按钮，不出现两个返回。
- Duo 等宽屏任务页可拖动中间把手调整两栏：列表宽度限制在 240–420pt，并为正文保留至少 400pt；真实折痕划分的两栏不允许移动。宽度在当前窗口内跨任务和旋转保留，不写入持久设置。
- 宽屏但不常驻侧栏时（如 Duo 竖屏），任务列表是悬浮抽屉：默认 400pt（不少于普通手机列表），与常驻侧栏共用同一个宽度记录，各自按范围夹取（抽屉最窄 300pt，右侧至少留 96pt 遮罩）。右边缘可拖动调宽、不显示把手，超出范围有弹性，松手弹回。遮罩上往右拖，列表带弹性变宽，越过约 96pt 立即回到首页（不播返回动画）；往左拖跟手收起，过三分之一或快速一甩即关闭，动得少回原位，轻点关闭；这些拖动不改宽度记录。任务页右滑不再返回，改为跟手拉出抽屉；返回走左上角返回键。Duo 竖屏抽屉可停留的最大宽度停在状态区之前。iOS 回首页时抽屉随路由一同弹出；Android 抽屉画在路由之上，仍先卸载再换页。
- iOS 首页列表留在自己的原生路由内，进入任务后仍可供返回动画显示；常驻侧栏独立保留列表内容，拖动分栏时不叠加尺寸动画。抽屉页面卸载时只撤销自己发布的内容，旧页面的清理不影响新页面，下一任务测量前不显示失效内容。系统顶栏已计入安全区时，磨砂高度直接采用原生测量值。
- Duo 竖屏的系统顶栏与状态栏同在一行；临时任务列表抽屉盖在系统顶栏之上，抽屉头部放在同一行（与时钟对齐），不排到整块状态区下方。首页标题宽度扣除系统上报的状态区（含实时活动加宽）及其前的按钮间距，长电脑名在右侧按钮前省略，不压到按钮下。
- Duo 外屏与横屏由系统竖栏承载远程桌面、显示按钮。系统（iOS 27.1）会把这一行的标题框收在中心两侧的对称空间里（外屏 466pt 宽时为 84–318pt），右侧白白空着；首页标题改放在顶栏右侧的自定义项里（自绘项不会被移进竖栏），铺满菜单后的空隙直到内容区右缘。规则与手机相同：放得下就居中（以内容区中线为准），放不下就贴住空间紧的一侧、往宽的一侧伸。手机上贴右侧按钮往左借，外屏上贴菜单往右用满再省略。系统让右侧项与菜单至少相隔约 33pt，贴菜单时名字开头画在右侧项之外，这一小段（约 26pt）点不到，其余部分和箭头可点。自定义项申请的宽度不超过菜单后的空隙：超过系统上限的项会在建栏时被收进竖栏的溢出菜单。排版只用系统回报的宽度；菜单的窗口位置等布局静止约 250ms 后再读，因为系统重建按钮时坐标会暂时失真。
- 侧栏切换任务沿用当前原生 Screen；`SessionTaskLayout` 将常驻侧栏放在任务内容边界之外，保留侧栏标题和测量槽。任务内容及侧聊删除保护按电脑及任务身份重建，搜索、停止、模型操作等局部状态和迟到完成不能影响新任务。
- 设置等整页滚动的二级页：顶栏透明、系统柔和边缘，内容滚到顶栏和底部指示条下面，无硬分界（设置、语音词典、账号注销、伙伴私聊、共享任务管理、资源列表）；设备详情只去掉底部色带。

## 输入框交互的共用边界

普通任务、新建任务与伙伴群聊（含话题）均通过 `ResizableComposerInputRow` 装配输入框的
卡片拖动、正文滚动、折叠进度和顶边调高把手；高度判据与手势裁决统一在 `useComposerResize`，
拖开后的焦点交接统一在 `useComposerDragOpen`，点击拉开沿用 `useComposerPillOpen`。
页面只提供草稿、附件、工具栏与发送操作，不另写手势阈值、调高状态机或拖开延时。

群聊主对话、话题和带伙伴身份标记的输入框，首次进入都默认收起为药丸，不自动聚焦；
点击输入框后才展开（同时保留与任务页一致的主动上拉打开）。话题或身份标记本身不能触发展开。
群聊不再用「有附件才展开」决定卡片形态；纯文字聚焦也展开，失焦回药丸。
普通任务与群聊的消息滚动通过 `ComposerPullThroughScrollView` 接入同一座桥，向下越过
输入框顶边后交给同一个 resize 状态机。iOS 群聊底部使用 `DockKeyboardBottomSpacer`
跟随键盘，底部安全区由 spacer 负责，避免页面与输入框重复避让；Android 保留系统缩窗路径。
