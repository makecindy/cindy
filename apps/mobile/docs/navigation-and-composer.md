# 移动端导航与新建输入框

移动端以侧边栏抽屉为主导航（左上菜单：任务 / 伙伴切换、搜索、设备管理、设置、切换账号、退出登录），
首页右下角保留悬浮新建按钮。按钮与输入框药丸同为 55pt（`composerGeometry.pillHeight`），坐在输入框
静止底线上：右缘 = 输入框右内边距 16pt，下缘 = 安全区 + 8pt。形变弹簧与时长登记在
`docs/design-rules/DESIGN.md §14.4`。

## 当前交互（iOS）

- 新建：原生 `CindyComposerMorphSource`（`modules/cindy-composer-morph`）接管按钮触摸，按下即横向拉长成等高药丸（不播系统按压），
  iOS 式利落弹簧（响应约 0.36s、刚度 305、阻尼比 0.67，单次过冲约 14pt 后停稳）；抬手进入新建页，滑出松开弹回、不导航。页面挂载前由替身玻璃生长，
  就绪后真实玻璃带速度接力；进入时不播推入动画，进入后恢复普通返回动画。只有首页开启形变。
- 输入框：新建、已有任务、伙伴聊天统一为 55pt 药丸，下沿同一条线；不自动聚焦。手动点药丸先向上
  拉开成完整卡片（原生），约 0.05s 后原生聚焦，键盘随后升起；输入框逐帧跟随键盘
  （均在 `ComposerDockKeyboardFollow.tsx`：新建页 `DockKeyboardBottomSpacer`，已有任务 `DockKeyboardLift` / `DockKeyboardViewportSpacer`）。
- 新建页输入卡固定在页面滚动区之外；已有任务输入卡仅正文与附件可滚动，发送、语音与拖拽把手保留在滚动视口之外。长文本、附件及键盘改变可用高度时仍能直接发送，收起再展开不重挂编辑器。
- 新建任务输入卡内的 `/` 命令和 `@` 资源候选面板使用可收缩的独立滚动视口；键盘弹出时保留输入与发送区域，候选项可在面板内滚动选择。
- 已有任务或恢复草稿的模型后来被关闭时，保留原模型身份与输入内容；模型面板说明需要重选，发送前要求明确选择开启模型，不自动换模型。远程目录仍只传开启模型的详情。
- 减弱动态效果：不播形变与拉开，直接到位。
- 伙伴对话：左上角为返回（回到伙伴列表）；Duo 系统栏已有返回时保留侧栏按钮，不出现两个返回。
- Duo 等宽屏任务页可拖动中间把手调整两栏：列表默认 400pt、宽度限制在 300–420pt，并为正文保留至少 400pt；真实折痕划分的两栏不允许移动。宽度在当前窗口内跨任务和旋转保留，不写入持久设置。
- 宽屏但不常驻侧栏时（如 Duo 竖屏），任务列表是悬浮抽屉：默认 400pt（不少于普通手机列表），与常驻侧栏共用宽度记录、默认值及 300–420pt 调整范围，Duo 横竖屏旋转保持实际宽度一致（仅窗口变窄或真实折痕等空间约束例外；抽屉右侧至少留 96pt 遮罩）。右边缘可拖动调宽、不显示把手，超出范围有弹性，松手弹回。iOS Modal 中边缘使用原生水平手势，与浮层关闭/拉伸协调；避免 JS responder 尚未获得移动事件就被原生手势截断。遮罩上往右拖，列表带弹性变宽，越过约 96pt 立即回到首页（不播返回动画）；往左拖跟手收起，过三分之一或快速一甩即关闭，动得少回原位，轻点关闭；这些拖动不改宽度记录。任务页右滑不再返回，改为跟手拉出抽屉；返回走左上角返回键。Duo 竖屏抽屉可停留的最大宽度停在状态区之前。iOS 回首页时抽屉随路由一同弹出；Android 抽屉画在路由之上，仍先卸载再换页。
- iOS 首页列表留在自己的原生路由内，进入任务后仍可供返回动画显示；常驻侧栏独立保留列表内容，拖动分栏时不叠加尺寸动画。抽屉页面卸载时只撤销自己发布的内容，旧页面的清理不影响新页面，下一任务测量前不显示失效内容。系统顶栏已计入安全区时，磨砂高度直接采用原生测量值。
- Duo 竖屏的系统顶栏与状态栏同在一行；临时任务列表抽屉盖在系统顶栏之上，抽屉头部放在同一行（与时钟对齐），不排到整块状态区下方。首页标题宽度扣除系统上报的状态区（含实时活动加宽）及其前的按钮间距，长电脑名在右侧按钮前省略，不压到按钮下。
- Duo 外屏与横屏由系统竖栏承载远程桌面、显示按钮。系统（iOS 27.1）会把这一行的标题框收在中心两侧的对称空间里（外屏 466pt 宽时为 84–318pt），右侧白白空着；首页标题改放在顶栏右侧的自定义项里（自绘项不会被移进竖栏），铺满菜单后的空隙直到内容区右缘。规则与手机相同：放得下就居中（以内容区中线为准），放不下就贴住空间紧的一侧、往宽的一侧伸。手机上贴右侧按钮往左借，外屏上贴菜单往右用满再省略。系统让右侧项与菜单至少相隔约 33pt，贴菜单时名字开头画在右侧项之外，这一小段（约 26pt）点不到，其余部分和箭头可点。自定义项申请的宽度不超过菜单后的空隙：超过系统上限的项会在建栏时被收进竖栏的溢出菜单。排版只用系统回报的宽度；菜单的窗口位置等布局静止约 250ms 后再读，因为系统重建按钮时坐标会暂时失真。
- 侧栏切换任务沿用当前原生 Screen；`SessionTaskLayout` 将常驻侧栏放在任务内容边界之外，保留侧栏标题和测量槽。任务内容及侧聊删除保护按电脑及任务身份重建，搜索、停止、模型操作等局部状态和迟到完成不能影响新任务。
- 设置等整页滚动的二级页：顶栏透明、系统柔和边缘，内容滚到顶栏和底部指示条下面，无硬分界（设置、语音词典、账号注销、伙伴私聊、共享任务管理、资源列表）；设备详情只去掉底部色带。

## 输入框交互的共用边界

普通任务、新建任务与伙伴群聊（含话题）均通过 `ResizableComposerInputRow` 装配输入框的
卡片拖动、正文滚动、折叠进度和顶边调高把手；高度判据与手势裁决统一在 `useComposerResize`，
拖开后的焦点交接统一在 `useComposerDragOpen`，点击拉开沿用 `useComposerPillOpen`。
页面只提供草稿、附件、工具栏与发送操作，不另写手势阈值、调高状态机或拖开延时。

群聊主对话、话题和带伙伴身份标记的输入框，首次进入都默认收起为药丸，不自动聚焦；
点击输入框后才展开（同时保留与任务页一致的主动上拉打开）。话题或身份标记本身不能触发展开。
群聊不再用「有附件才展开」决定卡片形态；纯文字聚焦也展开，失焦回药丸。
普通任务与群聊的消息滚动通过 `ComposerPullThroughScrollView` 接入同一座桥，向下越过
输入框顶边后交给同一个 resize 状态机。iOS 群聊底部使用 `DockKeyboardBottomSpacer`
跟随键盘，底部安全区由 spacer 负责，避免页面与输入框重复避让；Android 保留系统缩窗路径。

### 群聊与任务切换（2026-11-08）

Home 的导航入口按实际呈现方式统一经 `useTaskListNavigation`：顶层群聊与云端伙伴按页面类型复用现有原生 route key 和位置，仅关闭它上面的页面并完整替换目标参数；换群或换电脑不再每次叠加一个原生页面。正文仍按账号、电脑、群聊、话题身份重建，不能跨数据来源复用状态；话题页不会被当作顶层群聊容器。群聊打开原有任务时追加新的任务页面外壳，正文仍使用现有消息缓存；下次返回群聊不会重建其消息、草稿及滚动位置。反复在这两个目标间切换不会累加栈层数。消息里的普通链接不启用这项复用。

双栏或悬浮任务列表选择聊天是同级切换，原地呈现右侧内容；单栏首页进入任务、伙伴或群聊保留原生推入动画。`HomeSurface` 按实际呈现方式传入 `instantConversation`，不把路由复用等同于关闭动画。`TaskListTransitionContext` 先在根 Stack 提交无动画选项，再执行导航；导航状态提交（含无动画、原地参数切换）或原生转场完成后即释放切换锁；不能依赖无动画场景未必触发的 `transitionEnd`，让后续点击一直等兜底计时。不能只设置群聊目的页：返回时离开的原生 Screen 也决定动画。

`HomeRosterStoreProvider` 在账号边界内共享伙伴发现、群聊列表及有效连接回执；各 Home 只登记自身可见性。切换路由不应重新创建这些读取器，否则群聊旧回执丢失后会暂时被过滤，任务列表表现为重新载入。没有可见 Home 时暂停读订阅，账号切换销毁数据。现有撤权、连接代际、成员隐藏校验仍由原读取器负责；不把磁盘旧数据当授权。

路由失焦只暂停 Home 工作，保留本路由的原生容器及最后高度，直到路由卸载或离开适用屏幕形态。不能在 blur 时撤掉 `retainedHeight`，否则原生转场还没完成，侧栏就先被拆掉而闪空。首次侧栏排版的高度估计也须包含嵌入顶部间距及按钮底部间距，避免首个 onLayout 后整个列表下跳。

原生依赖补丁 `react-native-screens@4.30.1` 的 `RNSScreenView.didMoveToWindow` 按触摸处理器实际所属 view 决定绑定/解绑。浮窗停靠、覆盖路由和旋转会重复派发窗口移动；已经解绑的 handler 再解绑会触发 `RCTTouchHandler attached to another view` 断言。保留原有所有权断言，只跳过重复动作，不通过吞异常或关闭触摸处理绕过。此修复需要新原生包，旧安装不能仅靠页面热更修复；合并仍须完成冷更审核。

回归覆盖 20 次私聊/群聊数据读取器交接只启动一次、隐藏暂停/显示恢复、账号切换、新旧原生容器交接与普通导航保留动画。群聊首次无历史缓存时仍需读取真实内容；无动画切换不代表网络读取可以跳过。

不要用原生栈 PUSH/getId 将已有屏幕挪到栈顶：当前 Fabric Screens 对被移动的原生屏幕设置截图，旋转后可能冻结。也不要跨路由搬动包含原生 Screen 的整棵 Home/群聊树；视图控制器与触摸处理器的生命周期不能只靠 React 缓存代替。

模拟模式的伙伴列表含“伙伴协作测试群”（24 条合成消息，含代码和表格），通过真实远程资源 list/get 解析链路进入。回归覆盖导航复用、数据来源及话题隔离、普通链接回退、连续 20 次往返栈大小；真机仍需另外验证网络和 Release 性能。

### 同级选择与手势收尾的等待预算

`TaskDrawerPresentationProvider` 在聊天路由之上持有唯一浮窗外壳与动画值。
`useConversationTaskDrawer` 选中目标时同步派发导航，同时让外壳沿现有 motion token 向左退出；
消息切换不等待动画结束、计时器或浮窗卸载。离开的路由卸载后，原浮窗与内容仍保持原位完成退场，
新路由只发布下一份尺寸与操作上下文，退场结束后接管。任务、伙伴与群聊共用此入口。

退场期间首个目标获胜，列表不接受重复点击；结束只清理旧浮窗状态，不再派发目标第二次。
共享动画值归账号级宿主，不随旧任务 hook 卸载而取消；账号切换清理该宿主。
旋转打断退场时以原生停靠回执交接到常驻栏。常驻双栏直接切换，减弱动态效果直接收起。
没有共享原生宿主的旧包/平台保留路由内浮层的卸载后派发路径，避免原生换页与手势拆除竞态。
这不是额外预加载：只打开用户实际选择的目标，不新增请求或后台页面。

群聊正文以 Markdown block 作为静态复用边界。只有 Mermaid/公式 block 接收焦点/可见性，
普通文本、代码和表格不因后台暂停再生成 native selectable text。内容、主题、交互能力、
成员/mention 身份和回调改变仍更新；表格自己的宽度测量继续响应旋转。不使用跨账号全局
正文缓存，不忽略动态授权或身份变化来换取速度。

性能比较须使用同一模拟器/构建类型/模拟数据，先核对画面再采样。记录应用收到选择、overlay
卸载、目标 React commit 和后续帧，不能把设备控制命令耗时当交互耗时。开发版 React trace
用于定位重复工作，不可把其绝对毫秒或帧率当作真机 Release 结果。首次加载、热切换、常驻
侧栏、悬浮抽屉分别报告；没有同条件旧版实测时，只说明行为差异，不推算速度百分比。

### 伙伴主对话返回任务列表

伙伴主对话、顶层群聊与云端伙伴使用 `useTaskListBack` 返回现有 Home，按真实栈位置一次 dismiss 到列表，保留列表的搜索、折叠与滚动状态。冷启动深链没有 Home 时落到 `/devices`，旧的伙伴集合页沿用迁移清理。不得把主对话返回实现为普通 `back()`，否则同级切换留下的伙伴会成为返回目标。话题与普通消息链接仍保留各自的逐级返回语义。

模拟列表包含两个内容和消息 ID 各异的群聊，用于验证换群时既复用容器，也更新正确的正文。回归覆盖连续 30 轮不同伙伴/群聊切换不累加页面、完整替换参数清掉旧跳转目标、主对话一次返回列表，以及不等待无动画转场计时即可接受下一次选择。

本地 Debug 日志新增 `task list navigation settled`，仅记录耗时和完成来源（`state`、`transition`、`fallback`、`error`）；该时间覆盖同级导航协调过程，不代表网络加载或完整画面显示。仅在已有记录开关开启时落盘，不记录会话标识、名称或内容。

### 切换读取复用与失效边界（2026-11-08）

伙伴发现和群聊/伙伴列表保留同账号、连接代际、设备可用性与目标集合下的成功读取。
短时间隐藏再显示不会重复读取；隐藏时只登记收到的资源变化，不发请求，恢复可见后合并刷新。
连接、账号、目标、语言变化、前后台切换及显式刷新仍读取；失败或被取消的读取不得记作成功。
列表及插件提示复用还要求 sessions 订阅的确认身份连续有效；隐藏期间断订阅或确认身份变化立即重读。
展示复用最多 30 秒，过期后下次展示后台校验，不添加定时轮询。
这些展示数据不替代 Host 的权限校验。群聊发现结果相同时保持目标数组身份，避免无关列表重启。

`PluginPromptReadsProvider` 在账号边界内为聊天提示共享每台电脑的读取（含进行中的请求），
只保留需要 UI 批准的已安装插件，不保留市场条目。同一资源事件由 Provider 和页面处理时仅失效一次；
插件变化、连接/在线状态变化、撤权及前后台切换清空缓存；成功展示读取也受 30 秒复用上限约束。
控制器仍按任务/电脑创建，所有启用、批准、确认、取消操作继续读取即时事实并执行原有身份校验，
共享提示不得成为写操作依据。已确认的 sessions 订阅增加本地使用者不再重复读取项目别名；
新的 sessions 订阅确认和现有列表兼容路径仍同步别名。

本轮回归覆盖短时间 20 次返回无额外目录/列表请求、隐藏时收到变化、过期、重连、后台恢复、
失效中的旧回复与账号切换，以及共享插件提示后写操作仍拒绝已被移除的插件。
请求数量测试只证明重复工作减少，不能推算真机温度、CPU 或画面帧率。


### 浮动/常驻侧栏的统一进入规则（2026-11-08）

`taskListNavigationPolicy.ts` 是任务列表聊天入口的公共判据：任务、伙伴直达任务、顶层群聊、
云端伙伴，以及缺少 conversation 链接的伙伴资源解析页都属于聊天选择。
`HomeSurface` 只判断自身是否嵌在侧栏，不再分别给群聊和伙伴决定动效。

- 单栏列表进入聊天：普通原生 push；不启用侧栏容器复用。
- 浮动或常驻侧栏选择聊天：同级原地切换。公共导航入口给目的路由携带 `taskListEntry=sidebar`，
  并在派发前设置离开屏幕的无动画选项；根 Stack 从该进入信息决定目标屏幕动效。
- 伙伴资源解析后：`inheritTaskListEntry` 仅延续进入方式，不复制旧的聊天身份、焦点和一次性参数。
- 普通消息链接、设置、新建、群聊话题：保持原有导航行为，不因为窗口够宽就全局关闭动画。

不能把 JS `state` 事件当作原生转场已经完成。此前它提前清除了临时 `instant`，浮窗卸载与
伙伴页面挂载交错时又取到默认 slide；目的路由现在在整个生命周期保留进入方式，状态提交仍可
及时解锁下一次点击，不靠延长定时器掩盖问题。原地替换任务参数也保留此进入信息。

回归矩阵覆盖五种目标的侧栏/单栏入口、状态提交先于原生挂载、伙伴解析连续跳转、身份参数隔离；
Duo 内屏竖向浮窗的「群聊→伙伴」用真实触摸录帧对比，不以横屏常驻栏代替浮窗验证。


### 导航职责与维护入口

- `useGuardedPush` 仅管理真实路由焦点、防连点和释放锁；普通消息链接继续使用它。
- `useTaskListNavigation` 是任务列表的链接导航入口，统一串联抽屉关闭后的派发、上述守卫、
  原地切换回调、页面复用和转场。调用者只提供 `sidebar` 和抽屉退场调度，不再组合
  “是否复用”与“是否关动画”两个独立布尔开关。
- `taskListNavigationPolicy` 集中维护聊天目标分类、可复用参数边界、已有原生页面选择和进入标记。
  转场与复用使用同一个分类结果；新增聊天入口须在这里接入。群聊话题即使已在栈内也不复用为侧栏同级页面。
- `taskListSessionTarget` 统一首页、常驻栏、浮窗的任务目标解析：优先 canonical 电脑，回退物理电脑、
  再查列表索引；保留搜索消息定位。调用方继续提供自己的错误展示，不把订阅或 store 放进解析函数。
- 普通任务行保留原地选择回调，三种呈现共用目标解析与 `switchDrawerSessionInPlace`；
  页面保留自身的退出清理（例如取消旧任务的附件上传），以及群聊/任务各自的数据身份。
  伙伴旧历史链接去除资源外观时仍保留进入方式，避免规范化路由再次开启侧向动画。

共享入口负责优化切换；`useConversationTaskDrawer` 继续负责共有的拖动、关闭与导航排队生命周期。
不合并各自的数据订阅和草稿身份，避免为了减少文件数量扩大任务之间的状态共享范围。

### 跨聊天类型保留侧栏（2026-11-08）

共享数据缓存不等于共享界面实例。`SessionTaskLayout` 与 `BotGroupPaneLayout` 分别挂载自己的
`SessionListDrawer` 时，跨原生 route 切换会重建 Home；即使关掉滑入动画，也会先出现空白侧栏。

支持原生驻留容器的设备由账号级 `SharedTaskListProvider` 持有唯一的 Home / TaskDrawerHost。
各路由只通过 `SharedTaskListContent` 发布当前尺寸、回调及导航上下文；已失焦的路由不覆盖新
所有者，迟到的卸载也不能清空新所有者。账号更换会销毁该实例，普通设置页只暂停它。
常驻双栏的 docking slot 位于路由之外，切换原生页面不再用新的空 slot 覆盖旧列表；浮窗仍使用
Modal 内的 slot，旋转后的原生 onDock 回执继续负责移交结束。旧原生包保留原有局部容器路径。

群聊常驻列使用与任务列相同的顶部安全区，不再叠加聊天标题栏高度；浮窗仍覆盖系统栏并使用其
专属顶部偏移。消息、草稿与会话订阅的身份隔离不受共享侧栏影响。

回归必须跨任务/群聊的两个 route owner，不能只在同一路由内切换 sessionId：检查 Home 和
侧栏 slot 的实例保持、搜索状态、点击归属、迟到清理、旋转 onDock 与账号切换销毁。
