**![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)  Avoid rehydrating the Lead for progress reports**

When a Worker sends `report.state = 'progress'` and its Lead is no longer active in Maker, this branch is reached only after `resolveLead()` calls `ensureCapturedSession()` and `ensureSessionFromMeta()`, which can start a Lead session and run remote preflight. That can launch or reconnect an agent—or fail before `recordWorkerReport()`—even though this path never uses the Lead session or dispatches a message. Resolve the Worker link and persist progress before rehydrating the Lead.
