# 法语、西班牙语复核

本分支已对齐 main `f283ccebd3`。main 已通过 #8157 和 #8163 接入并补齐
`es`、`fr`、`de`、`pt-PT`、`pt-BR`，Desktop 和 Mobile 共支持 10 种界面语言。
本次沿用这些目录，不再重复新增 `es-419`。系统西语地区变体统一匹配 `es`。

复核范围：

- 检查全部语言的目录结构、占位符、富文本标签和技术标识；结合调用点区分合法差异。
- 逐条复核相对旧基线新增或修改的 311 条 Desktop 英文源及其法语、西语译文，
  并复核登录、删除账号、模型设置和 Mobile 对应入口。
- 修正西语导入指南中的 JSON 字段与枚举值、模型替补与文件备份的误译、状态和动作的混淆、
  语音输入框说明及两端术语不一致；修正法语上传方向、授权规则和部分生硬文案。
- 新语言的跨任务原话包装沿用旧端识别的英文格式；继续严格接受已保存的各语言历史回执。
  回归覆盖新发送格式、旧法语回执和篡改拒绝。

验证通过：Desktop 371 项与 Mobile 565 项定向测试、两端类型检查、语言目录和术语检查、
测试规范门禁、开发文档合同检查。跨版本回执回归先复现 5 个新增语言发送失败，再验证修复。
定向 UI 共 20 个组合通过并目检：法语／西语的模型继承设置、协议弹窗、单个及批量导入，
以及法语性能报告的开始／完成页面，均覆盖浅色与深色。没有运行全站全部 UI 用例。

本次是代码、目录和重点文案复核，不代表全部界面均已逐屏或由母语使用者验收。
手机实机、macOS 原生权限引导尚未实测。旧实现已保存在 rebase 前的本地 Git stash。
