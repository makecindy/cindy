# 社区贡献墙 · Community credits

[查看已发版的社区贡献 · View released contributions](https://github.com/makecindy/cindy/blob/community-credits/README.md)

每条记录都能找到改动、反馈者希望公开的名字、实现 PR，以及首次包含它的公开版本（含 beta）。贡献墙由发版工作流生成，第一次运行后可访问。署名办法见[贡献指南](CONTRIBUTING.md)。

Each entry links a change and its contributors to the implementation PR and the first public release that included it, including betas. The release workflow publishes the wall on its first run. See the [contributing guide](CONTRIBUTING.en.md) for credit options.
