# 执行端的模型用量账本

桌面执行端为 Claude Code、Codex 和 Pi 记录模型用量。每次有可靠的模型明细时，消息回执保留各模型的普通输入、输出、缓存读取和缓存写入，四项分别与整轮计数对账。价格缺失或订阅费用为零时也保留 token。对供应商内部未披露的后端，只能观察到它提供的模型标识。

个人用量页继续按设备的本地日历记账。同一笔本地模型用量在同一事务内也写入 UTC 日期、接入来源、计费方式、模型四个维度的日汇总。Pi 按原生请求回执去重，后续的价格修订只更新金额。远程会话在控制端显示的副本不写入这张 UTC 表。没有运行这个版本的执行端不会产生新日账。

旧消息仍可正常读取。遇到只有多个模型名和整轮计数的旧消息，可在同范围内改读已经存在的个人模型日账。旧日账的订阅/API 标志只说明计费方式。有历史原生路由凭据时可以另做同范围对账，否则无法从这个标志还原供应商。

## 授权后的本地导出

用仓库根目录下的命令读取指定的账号数据库。输出为 JSON Lines，可以读入区域汇总或单人试点报表。

```sh
python3 scripts/export-token-usage.py --database /path/to/profile.db
```

每行包含 UTC 日期、公开接入来源、计费方式、模型、四类 token 及合计。独立辅助调用从自己的回执取数；供应商未说明的计费方式显示为未记录。公开预设的配置与实际接入匹配时才保留其名称，例如 Magpie。路由或模型没有提供更深一层的信息时，报表只能展示执行端观察到的这一层。

导出默认合并私有来源和私有模型。经授权需要区分它们时，传入 `--private-label-key-file`，该文件须包含至少 32 字节的随机密钥，并限定在一个统计范围内。生成的标签可在同一范围内关联，属于假名化数据。导出仅包含汇总值，不输出账户、会话、设备、端点或私有名字。命令仅读本地数据。执行端快照重导时应覆盖同一范围的旧版本；区域汇总或 TapDB 消费者不能把不同版本直接相加。
