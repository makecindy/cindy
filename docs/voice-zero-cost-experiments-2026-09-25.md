# 零新增开销的语音处理实验

2026-09-25，Node 22 / Apple Silicon。本轮不联网、不启动客户端、不使用麦克风，
不增加产品后台请求、连接、预热或模型调用，也不改变音频格式、包数与压缩参数。
原先已经批准的原生静音预热有一次启动工作量，不属于本轮的零新增开销改动。

微基准是进程内 CPU 耗时，不是用户感知的录音启动或首字时间。

| 候选                                                    | 对照结果                                                                                                              | 选择                                                            |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| 单次分配音频协议包，替代多个 Buffer 与 concat           | 每批6000次，ABBA重复，旧84.64ms，新83.87ms，约0.9%差异；37种输入逐字节一致                                            | 收益接近噪声，不采用                                            |
| 遍历时选择最长识别文本，替代递归收集、trim/filter和排序 | 每批30000次，ABBA重复，旧55.13ms，新27.61ms，约49.9%减少；29种输入结果相同                                            | 采用；进一步用200种生成输入锁住旧语义                           |
| 把重连缓存 filter 与时长求和合成一次遍历                | 每批30000次，旧中位数40.12ms，新42.53ms；20种输入相同                                                                 | 略慢，不采用                                                    |
| gzip level 1 替代默认压缩                               | 40ms静音包从30字节增至34字节；随机音频未测得计算优势                                                                  | 有流量代价，不采用                                              |
| 输入采样率已等于目标时，省去 Array.from 的中间数组      | 实际 worklet 源码在 VM 中每批处理4000个128样本输入，ABBA重复，旧79.96ms，新74.14ms，约7.3%减少；16k/44.1k/48k输出一致 | 采用，同步覆盖 ScriptProcessor 回退路径；只影响无需重采样的输入 |

输入覆盖空包、10ms/40ms音频、300ms尾部静音长度、固定伪随机PCM与合成波形。
这些是协议/计算输入，不代表真实语音的压缩率或识别效果。压缩组计时仅是探索性单批，
不能据此作稳定CPU收益承诺；仅凭确定的包体变大，已足够排除其为零代价方案。

同采样率路径只在本次处理回调内读取输入，仍立即把数值保存到原有待发缓冲，不持有浏览器
可复用的 Float32Array。测试覆盖输入不被修改、浏览器随后覆盖输入不影响待发音频。
worklet 微基准使用模拟端口，无真实音频线程调度，不能等同整机CPU下降7.3%。

文本提取保持大小写不敏感字段匹配、trim、最长字段选择和同长度首个字段优先，
不会改变送给用户的识别结果。典型基准中单次仅节省约0.9微秒，收益是更少中间分配与
计算，不应描述成可感知的毫秒级或秒级提速。

验证：85项定向回归测试通过，覆盖SAUC协议、文本提取、两种音频路径、空闲麦克风与
录音启动。未启动开发版，未做真实云端识别或麦克风实测。
