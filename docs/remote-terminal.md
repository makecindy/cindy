# 远程终端：使用前提与限制

本文说明 Desktop 最小远程终端方案的使用前提与限制；实现和发布状态以实际版本及验证结果为准。需求跟踪：[远程任务终端面板 #8719](https://github.com/makecindy/cindy/issues/8719)。

- 控制端需要可用的系统 SSH 客户端，目标主机需要可访问的 SSH 服务和可用账户。连接使用系统 SSH 配置、认证方式和 `known_hosts`；首次信任或认证提示由用户处理。主机密钥变化时，应先核实身份并自行处理信任记录。Cindy 禁止该连接的 Agent 转发、端口转发和本机 `LocalCommand`，并覆盖别名的 `RemoteCommand`，以便执行任务目录启动命令；`ProxyJump` 等系统 SSH 选路仍由 OpenSSH 处理。
- 设备互联提供任务上下文，SSH 从控制端直接连接文件所在的目标主机；设备互联可用不代表 SSH 网络可达。需要绑定时，用户须自行核对并选择或填写目标 SSH 主机；设备身份本身不是 SSH 凭证。
- 远端需要 POSIX 环境和绝对工作目录。启动时先尝试进入任务目录，再启动远端登录 shell；目录不可进入时不会回退到其他目录。登录 shell 的启动配置仍可能再次改变当前目录，可用 `pwd` 检查。
- 远端字符编码依赖远端系统及用户的 locale 配置；需要正确显示和输入 UTF-8 时，请在远端配置可用的 UTF-8 locale。
- 首次提交连接设置时保存非秘密绑定，保存不代表 SSH 已认证；连接失败后可以修改设置。关闭终端不会撤销已经提交的连接偏好。
- 当前没有 SSH 认证及 shell 就绪检测：终端进程已启动不代表认证成功或已进入交互 shell。SSH 的认证提示和错误显示在终端中。切换任务、迁移窗口或 renderer 重载后，重新接管已退出实例时会补发它的退出状态，供界面显示退出结果与重启入口；接管本身不会创建新 shell。
- 连接准备使用当时的目标和目录快照，有效期为 30 秒；期间修改任务位置不会改写该快照。多个窗口并发提交连接设置时，以最后完成的保存为准。
- 页签固定属于创建时的任务，窗口迁移保留同一 tab ID。主进程接管已有 SSH 实例时复验原任务、设备与当前账号身份；启动票据另绑定账号代次。输入、缩放和重启只接受当前受信窗口。主窗口关闭已弹出的标签时使用创建时保留的任务/设备上下文；当前拥有该 PTY 的窗口也可按 ID 关闭。关闭失败会提示并保留标签，合并窗口保留进程。
- 临时账号边界及明确的同账号投影修复会作废未消费票据，保留已有 SSH；边界期间拒绝操作，修复完成后继续使用原进程。退出登录、切换账号或认证域等其他强制代次变化会结束远程实例并通知退出，不结束本地终端。被回收的会话通过重启入口重新取得主进程授权，不复用旧票据。
- 字体、字号、应用配色与面板布局复用控制端的本地终端；提示符及 shell 启动配置来自目标主机，不复制控制端的主题脚本或凭据。此最小方案不保证两端提示符相同。
- 本机 SSH 任务自动采用对应的系统 SSH 别名或已配置主机；设备互联任务的绑定仅在控制端当前账号保存，文件为账号目录下的 `terminal-remote-bindings.json`，只含主机、用户名、端口和私钥路径，不读取或保存私钥内容和密码。私钥绝对路径仅由主进程管理；界面通过不透明引用选择配置，引用失效后须重新选择有效配置，不会自动丢弃私钥设置。被控端无需安装终端插件；手机和跨账号共享任务不提供此入口。
- 终端 IPC 只在控制端本机调用，不加入 device-link invoke/push 白名单；设备互联只复用现有设备目录和任务元数据查询，不发送终端字符流，不改变官方或自建中转协议。旧被控端只要提供完整任务元数据即可使用；不完整时拒绝启动，不回退到本机 shell。
- 远程终端与本地终端共用 PTY 生命周期：切换标签或收起侧栏时保留运行中的实例，关闭标签时释放；退出后重启会使用该终端原有连接和目录创建新 shell；修改绑定或任务目录后，新建标签使用新设置。没有终端输出的历史回放或断线后原 shell 的无损恢复；重启不会自动重放命令。
