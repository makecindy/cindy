# 附件预览：三端共享行为合同

2026-11-01。适用于 Desktop、iOS、Android；任务、伙伴私聊、群与话题、输入区、文件浏览、成果和插件媒体。统一查看方式，读取授权仍由各来源负责。

## 打开与返回

Desktop 预览浮在原界面之上；除图片查看器外（2026-11-25）均为非模态浮窗：默认贴右、可拖动、可调整尺寸，不画遮罩、不圈禁 Tab、不锁背景滚动，背景消息保持可读 / 可滚动 / 可选中 / 可复制，消息栏可用。关闭走标题栏按钮、Esc 或浮窗内空白背景，点背景对话不关闭。图片查看器在本分支仍点窗外关闭，其非模态改造由另一张已发布 PR 负责；打不开的文件用小窗。手机（含 iPad）全屏，按钮与内置浏览器一致浮在页面上。视觉见[附件预览视觉与交互](../design-rules/attachment-preview.md#呈现方式用户定稿-2026-11-03)。所有查看器都有固定的文件名、关闭和文件操作入口。关闭在加载、失败、播放、放大时可达；关闭仅结束查看，不能删除附件、撤回消息或离开来源任务。桌面保留 Esc 与焦点归还：打开时焦点进入预览窗，关闭时回到入口；Tab 不被圈禁，可以到达消息栏。手机保留系统返回、安全区和原生播放器。未保存标注由原标注流程询问保存、放弃或继续；不能通过切换附件绕过。

同一条消息、待发托盘或文件列表可提供明确集合。Desktop 任务里点开的图片例外（用户定稿 2026-11-24）：集合是该任务已加载历史里的全部图片，跨消息、跨回合按对话顺序排列，包括用户上传、工具产出、插件卡片和回复正文嵌入的图（Markdown 与组件图片，代码块里的示例不计）；带标注的上传图同样在内，打开即可继续标注。被插件卡片替换的回复只计卡片里的图。尚未加载的更早历史、仍在输出的回复不在集合内，从这类位置点开只看这一张。同一张图出现多次时从点开的那一处开始。文件、视频、音频仍用所在消息的集合，从文件切到同条消息的图片后不再跨消息。集合由消息数据推导，进入时固定其身份与顺序，不扫描整页 DOM、不将新到消息插入当前集合。翻页时标题跟随当前图片。Desktop 显示上一项 / 计数 / 下一项，到边界禁用，计数可打开文件列表。手机不显示集合导航（不放上一项 / 下一项，也不显示「3 / 7」计数，用户定稿 2026-11-07）：图片、视频在看图器里左右滑动切换，文件浏览里能横滑的文件照旧横滑；PDF、3D 模型、流程图等不能横滑的附件，关掉预览再点下一个。只有一项时不显示无意义导航。纯图片消息原有图库和缩略图行为继续保留。

Desktop 非模态预览的 Tab 不圈禁在预览窗内（DESIGN.md §14.2）；Esc 先交给当前菜单、提示气泡、全屏播放器或嵌套查看器，
再关闭查找，最后才关闭文档；同一次按键不能跨层关闭。Markdown 阅读态的 Ctrl/Cmd+F 查找正文，
被全屏媒体或嵌套查看器覆盖时不切换为源码。源码和纯文本使用预览内的查找栏，查找快捷键跟随
用户改绑；预览处于前景时背景编辑器、项目搜索和语音输入让路，焦点回到背景后由背景自己处理，
不能抢焦点或被同一次 Esc 关闭。
回归见 `TextLightboxInteraction.test.tsx` 与
`apps/desktop/scripts/fixtures/markdown-preview-find/ui-page.mjs`。

## 类型能力

| 内容 | 标准查看行为 |
| --- | --- |
| 图片 / GIF / SVG | 原图、缩放、平移、适应、原始尺寸、原件保存或分享；可用入口继续提供标注。图片始终保持比例，SVG 走既有图像安全路径。手机全屏显示，缩放用捏合 / 双击，原始尺寸在「更多」（见[手机外壳](../design-rules/attachment-preview.md#ios--android)）。 |
| 视频 / 音频 | 应用内播放器、进度和平台支持的音量 / 全屏；宿主关闭与保存独立于播放器控件。切换或退出销毁/暂停旧播放器。 |
| PDF | 三端内嵌 PDF.js；页码、翻页、缩放、文字层与查找。手机缩放用捏合 / 双击，放大后重新清晰绘制，不放缩放按钮。手机离线引擎不依赖第三方网页；30 MB 上限保留保存原件的出口，密码仅交给本地阅读器。 |
| 文本 / 代码 / JSON | 原文选择复制、查找、换行、行号与引用位置；既有长文本编辑不变。读取上限与截断提示继续生效。 |
| Markdown | 阅读 / 源码切换、原有链接与引用能力；源码复用公共文本阅读器。 |
| HTML | 保留既有网页预览、导航与脚本/资源策略；更换外壳不增加网页权限。群附件沿既有受限阅读器。 |
| Mermaid / draw.io | 图形与源码、缩放、既有导出能力；手机使用离线渲染资源。 |
| GLB / glTF | 模型查看、旋转、缩放和复位；手机读取已授权本地副本（50 MB 上限）。外部资源需原传输路径明确提供，不从文件内容推导额外授权。 |
| 其他文件 / FBX | 显示文件名与类型，提供保存/分享或已有外部打开；不把无法解码的文件伪装成可预览。 |

## 来源与生命周期

- 本机、另一台电脑、SSH、Chat Server、插件授权资源继续走现有 resolver。UI 不把远端绝对路径解释为手机本地文件，不公开签名 URL 或凭证。
- 保存/分享交付原件，不能导出播放器截图冒充原件；手机复制至受控临时目录，系统分享完成后释放，查看期间保留缓存租约。
- 关闭或切换中断读取；迟到的结果不再应用到已卸载查看器。账户隔离、插件 grant、服务端附件授权和危险文件下载策略不变。
- 错误状态保留关闭；可重试的读取/解码错误提供重试。未知格式可直接分享，不要求先成功预览。
- 过程图片仍留在展开的工作过程里，伙伴成果只展示已有成果，不把临时文件升级为成果。

## 实现入口

共享类型判定在 `packages/maker-shared/src/attachmentPreview.ts`。Desktop 使用 `PreviewChrome`、`AttachmentCollection` 与共享非模态外壳 `PreviewWindow` / `previewWindowGeometry`，经 `TextLightbox` / `FileLightbox` 分派既有内容渲染器；视频、Mermaid、模型、工具 payload 与集合 fallback 都落在同一外壳上。图片查看器暂沿用 `PreviewChrome` 的模态外壳，因此旧导出继续保留。Mobile 使用 `PreviewChrome`、`RemoteAttachmentPreview`、`DocumentPreviewChrome` 和类型阅读器；任务、群附件、草稿、插件媒体与伙伴成果接入同一合同。

移动端离线资源由 `node apps/mobile/scripts/sync-document-preview-assets.mjs` 从现有依赖和 Desktop draw.io vendor 生成；更新依赖后重新生成，禁止手改生成文件。没有新增 native dependency、协议字段或授权记录迁移。

验收与尚未完成的环境补充检查见 [本次证据](../design-evidence/2026-11-01/attachment-preview/README.md)。本合同描述行为要求；组件复用或代码存在不能代替对应来源的实机验证。
