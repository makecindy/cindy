# 思考内容的手动翻译

对应需求：[#7334](https://github.com/makecindy/cindy/issues/7334)。

- 用户展开有可见原文、且已结束的思考块后，可以手动点击「翻译」。仅展开不调用模型；不增加全局自动翻译开关。
- 翻译目标为当前界面语言。完成后显示译文，标注「机器翻译」，可切换原文与译文；切换不重复请求。
- 点击前说明原文将发送给设置中的辅助模型服务，并产生额外用量。沿用已有辅助模型配置和可用性约束。
- 原文、引擎状态、签名、消息历史与后续模型输入保持不变。译文只存在于当前组件的临时展示状态，不保存到历史，不向插件暴露思考原文。
- 原文变化、切换语言、账号、设备或任务后，不得显示旧请求的结果。失败保留原文，用户可以再次点击翻译；不自动重放翻译请求。
- 空内容、隐藏思考和仍在生成的思考不提供翻译；超过 16,000 字符时提示暂不支持，不静默截断。
- 桌面与手机的独立思考块、工作过程内的思考行都提供入口。远程查看时使用任务所在桌面的辅助模型服务；旧主机不支持时提示更新，不回落到控制端服务。SSH 工作区沿宿主桌面的辅助模型路径，无需读取远端文件。
- 展示沿用思考正文排版、标准按钮和语义颜色；适配 Light / Dark。设计依据为 `docs/design-rules/DESIGN.md` §3、§4、§5、§10、§11，以及 Mobile 设计指南 §3。

实现入口：Desktop `ThinkingCard.tsx` / `WorkGroupBlock.tsx`，Mobile `MessageRenderer.tsx`；辅助请求为 `maker:translate-thinking`。
