# 供应商设置：统一身份、状态与操作

制定日期：2026-09-09。适用于现有与未来新增供应商，包括本机登录、独立授权、
API 接入、Cindy AI 与本地模型服务。本文定义统一合同；当前实现与验证边界见末节。
视觉正本见 [DESIGN §4 Provider detail header](../design-rules/DESIGN.md#provider-detail-header)。

## 1. 一个连接，一套顶部

供应商品牌与连接实例分开：同品牌的多个账号使用同一品牌图标，允许不同显示名。
改名不改变品牌、模型目录、凭证、限额或调用目标；绑定仍遵守
[多连接的身份与隔离](./model-metadata-precedence.md#多连接的身份与隔离)。

顶部固定呈现：品牌图标；连接显示名、接入类型；账号或来源说明；
连接状态、至多一个主要操作、一个更多菜单。不得因为 builtin/custom 分类而换一套交互。

- 名称显示该连接的用户命名；未命名时使用默认名称。同品牌重复添加时默认名称帮助区分账号。
- 详情顶部不重复显示模型数；数量保留在左侧供应商列表，按统一模型列表去重统计。
- 接入类型说明实际使用方式，例如 ChatGPT 订阅、API、本地服务；不是程序内部的存储分类。
  已取得实际套餐时，订阅标签显示 ChatGPT Pro、ChatGPT Plus 等套餐名；仅在套餐未知时回退到通用订阅名称。
- 新增官方账号不因为存入自定义配置而显示“自定义”标签；Beta 等产品状态另有明确依据才显示。
- 副标题优先提供账号识别信息，并说明本机登录或独立授权来源；无账号信息时仅显示来源。
  API 连接显示去除凭证、用户信息及敏感查询参数的服务地址。本地服务显示可识别的运行位置。
- 品牌根据可信品牌资料或已有域名解析规则确定，不从用户可编辑的显示名猜测；兼容 OpenAI
  协议的第三方不自动视为 OpenAI 官方。

## 2. 状态与主要操作

连接状态、是否启用、用量是三个不同维度。用量读取失败不等于账号断开；
停用仍保留连接状态，以独立的停用说明及启用入口呈现。

| 连接状态 | 顶部主要操作 | 规则 |
|---|---|---|
| 未连接／未配置 | 连接／配置 | 授权或 API 表单由连接方式决定，入口位置不变 |
| 连接中 | 取消（支持时） | 明示进行中；不支持取消时显示进行状态，防止重复提交 |
| 已连接 | 断开（支持时） | 状态和动作分开显示；不支持断开的来源不伪造按钮 |
| 已配置但未验证 | 验证（支持时） | 保存 API key 成功不能单独证明已连接；无验证能力时如实显示已配置 |
| 需要重新授权 | 重新连接或来源对应恢复入口 | 本机共享授权可能需要打开来源 App；说明原因与实际影响 |
| 状态读取失败 | 重试（支持时） | 保留最后已知状态并注明未更新，不能直接改成未连接 |

以上为语义名称；实际界面文案沿用术语表和本地化体系，不直接输出状态枚举。
首次读取无历史状态时显示读取中。失败说明、授权码及恢复指引进入顶部下方说明槽，
不能藏在按钮 tooltip 中。后台刷新不得清空已知身份或用量后再重建顶部。

## 3. 操作位置与影响范围

更多菜单顺序统一：重命名、编辑连接设置、停用／启用、删除连接；只显示确实支持的动作。
已有供应商特有低频操作仍放同一个菜单，按用途分组；删除位于末尾并与普通动作分隔。
编辑、删除不再作为新增供应商独有的裸图标并排暴露在标题右侧。

- 重命名只改显示名。编辑连接设置仅出现于有可编辑连接参数的来源。
- 停用只阻止该连接被用于后续路由，保留凭证与配置；启用恢复该连接，不替换账号。
- 断开解除当前连接的授权使用，保留供应商条目与可恢复配置；不能将删除条目称为断开。
- 删除移除可删除的用户连接及其专属配置；不删除历史内容，也不静默转绑其他同品牌账号。
- 断开、删除的确认规则取决于真实影响，不取决于 builtin/custom。确认说明要点名当前连接。
  共享本机凭证若会被清除并影响其他 App，必须明确说明；只读来源不应提供无法执行的登出。
- 这次视觉收敛不修改底层凭证归属、断开范围或现有授权边界；适配前核实实际行为，不以
  更换按钮文案掩盖差异，也不额外实现系统全局登出。

## 4. 用量与扩展区域

订阅用量或账户资产放在顶部下方固定区域，与身份行分层；各供应商只提供数据和必要的专属操作。
配额、余额、重置时间保持各自真实含义，不为外观一致而虚构不存在的数据。
设置页复用用量卡片的嵌入呈现：各窗口分别显示进度条、剩余百分比、重置倒计时与已有趋势提示；设置页面空间充足时额外保留具体重置日期，紧凑用量卡片优先倒计时；不再维护纯文字摘要。只返回周窗口时仍完整显示，套餐已知而窗口缺失时保留套餐信息。
OpenAI、Claude 和 Grok 的订阅连接都按连接 ID 读取，不按品牌名共用账号缓存；套餐名称与用量卡片共用格式化规则，不把模型专属促销额度当成整个账号的额度。
所有限额窗口和供应商摘要统一显示剩余百分比（100 减已用，限制在 0–100），
进度条填充及无障碍数值同步显示剩余；告警与节奏仍依据实际消耗计算。
Grok 产品消耗是共享池贡献，不是独立限额，不反算成产品余额，限额卡片仅显示共享池剩余。
历史费用、实际消耗明细继续保持原计量语义。
缓存回显及隔离遵循 [统一模型选择与订阅用量规则](./model-selector-unified.md)。
用量刷新不占用连接操作的位置；读取失败保留缓存，断开或账号变化按权威事件清理。

## 5. 实现与验证边界

`ProvidersSection.tsx` 的 `DetailHeader` 统一渲染类型化状态、至多一个主要操作、
编辑菜单动作与末尾删除动作；不再接受任意 `trailing` 布局。连接状态、主操作和更多菜单
在同一组内布局，长名称压缩或换行时更多按钮不会单独掉到下一行。

- OpenAI 本机登录与新增账号共用顶部；独立账号和其他 OAuth 复用 `GenericOAuthHeader`，
  各自保留真实登录、取消和恢复适配。新增 OpenAI 的重命名复用既有仅修改名称的弹窗。
- Anthropic、xAI、API、本地服务和 Cindy AI 使用同一状态/动作槽位。API key 的存在仅显示
  已配置；更换 key 收入菜单。Cindy AI 按既有资产模块合同保留凭据操作在菜单中的位置。
- 可编辑自定义连接提供编辑入口（含名称）；不可编辑的内置来源不新增改名存储或伪造操作。
- 身份、资产与授权说明保留原适配。没有权威状态来源的读取失败/验证状态不在前端编造，
  不因此次布局统一新增 IPC、数据库字段或授权检测请求。
- 回归覆盖原有深链、只读本机凭证、恢复、资产和模型列表，以及新增 OAuth 菜单、
  API 已配置、恢复覆盖旧连接状态、取消后的迟到授权结果。真实账号操作与双模式目检
  需单独记录，不以组件测试或复用主题样式代替。

新增供应商应复用上述入口，仅补连接适配与确有必要的专属说明/资产内容。

## 6. 同品牌多个订阅账号

OpenAI、Claude 和 Grok 都允许新增独立登录账号。每次新增生成唯一连接 ID，凭证、刷新、模型发现、用量和断开操作始终绑定这份连接；任务不能凭品牌或显示名选择账号。
同品牌连接共用模型定义和已有 Harness 能力，账号发现只约束该连接的可用模型。重命名只修改显示名，断开或删除一份连接不影响同品牌其他账号及历史消息。
已有本机连接继续保留；新增 Claude 和 Grok 登录写入 Cindy 的账号专属凭证存储，不覆盖本机 Claude Code 或旧 Grok 连接。远程执行沿用各 Harness 已有能力边界，Grok 的 Pi 远程请求经主机代理使用所选连接，凭证不写到远端。
