# 手机新建任务的默认电脑与工作区

> **状态**：权威产品规则（authoritative）
> **读取时机**：修改 Android 新建任务页的默认电脑 / 默认工作区、桌面小组件入口，或这几项偏好的存储与回退逻辑之前。
> **适用路径**：`apps/mobile/app/sessions/new.tsx`、`apps/mobile/src/session/newSessionDefaults*.ts`、`apps/mobile/src/session/newSessionOrigin.ts`、`apps/mobile/src/session/NewSessionDefaultsSheet.tsx`、`apps/mobile/src/session/useNewSessionWorkspace.ts`、`apps/mobile/src/device-link/DesktopEntryHost.tsx`
> **要点**：两份档案分别是「应用内新建」与「桌面小组件」；显式默认优先，未设置时沿用原来的「记住上次」；入口明确带的电脑 / 项目永远优先；具体项目绑定所在电脑；默认保存在本机、按账号区分。

## 1. 术语

| 叫法 | 指什么 |
| --- | --- |
| 新建任务 | 手机新建页最终创建的那条任务（用户面向叫「任务」，不叫「对话」） |
| 默认电脑 | 新建任务时默认在哪台电脑上运行 Agent |
| 默认工作区 | 新建任务的「项目 / 对话」二选一；选项目时还包含具体项目目录 |
| 工作目录 | 项目对应的那个目录路径；设置行里的「工作区」不叫「工作目录」 |
| 应用内新建默认 | 应用内所有新建入口使用的档案 |
| 桌面小组件默认 | 点桌面「Cindy 任务」小组件时使用的档案 |
| 跟随上次 | 沿用新建页原来的「记住上次选择」逻辑；不是一个新的记忆 |

「组件」「小组件」「小工具」都指 Android 主屏幕上的 App Widget；用户可见文案按现有平台用语（zh-CN「小组件」、zh-TW「小工具」）。

## 2. 两份档案与初始值

| 档案 | 使用场景 | 电脑初始值 | 工作区初始值 |
| --- | --- | --- | --- |
| 应用内新建 | 首页 ＋、任务页新建、项目 ＋、分享 / 通知等所有应用内入口 | 跟随上次 | 跟随上次 |
| 桌面小组件 | 仅「Cindy 任务」桌面组件的 `desktopEntry=1` 新建任务深链 | 跟随应用内默认 | 跟随应用内默认 |

- 组件档案的每个字段单独选「跟随应用内默认 / 跟随上次 / 具体值」，可以只覆盖一项。
- 初始值等于功能上线前的行为：不打开设置弹窗，应用内仍按上次选择，组件也继承应用内，因此没有可见变化。
- 设置入口只在 Android 新建任务页右上角出现；iOS 不显示，也不改变原有行为。设置不跨手机同步，不影响电脑端。

## 3. 打开新建任务时的解析顺序

### 3.1 电脑

1. **入口明确指定**（项目 ＋、任务页新建、首页正筛选某台电脑、入口只有一台候选）→ 用入口的电脑。
2. 当前档案指定了电脑 → 用它。这次用不了（离线、被撤权、不在可打开目录里）→ 回退到第 3 步，**不改写已保存的默认**。
3. 跟随上次：上次在新建任务页手动选过的电脑（仍在可打开列表里）→ 入口带来的电脑（通常是首页当前可用的第一台）→ 第一台可用电脑。

组件档案的「跟随应用内默认」先按应用内档案解析；应用内也不指定具体电脑时，继续走第 3 步。若回退链最终仍落在配置的那台电脑上，不算「用不了」，不显示提示。

### 3.2 工作区

1. **入口明确带项目目录** → 用它，项目模式。
2. 当前档案指定「对话」→ 对话。
3. 当前档案指定某个项目 → **仅当它绑定的电脑就是这次解析出的电脑**时使用；否则按第 4 步。
4. 跟随上次：上次手动选的模式（项目 / 对话）→ 项目模式下：该电脑上次手动选的目录 → 该电脑最近项目里的第一个 → 打开远程目录浏览器。从未记过模式时保留新建页初始的「对话」，不擅自换成最近项目。

组件档案的「跟随应用内默认」先按应用内档案解析；「跟随上次」跳过应用内默认直接走第 4 步。

### 3.3 不可用与提示

- 默认电脑这次用不了时，在设备选择器上方显示一行：「默认电脑『X』这次用不了，已用『Y』。」用户手动换电脑或工作区后消失；保存的默认保持不变。
- 默认工作区这次不适用时静默回退到「跟随上次」；选择器会显示实际使用的模式 / 项目。
- 目录不存在不预检查（远端多一次往返，且现有记忆目录也不检查）；创建时仍走原有错误卡。

## 4. 设置弹窗

- 标题「新建任务默认」，副标题说明只影响这台手机；两组「在应用内新建」「从桌面小组件新建」，每组两行：默认电脑、默认工作区。
- 点一行在同一弹窗内进入二级选择，选中即保存，没有单独的保存按钮。
- 「跟随上次」「跟随应用内默认」行显示当前实际会用的值作为次级说明；不可用时显示「现在不可用」。
- 弹窗底部一个默认收起的「跟随上次怎么选」，按电脑 / 工作区写出第 3 节的顺序；每个选择器里的「跟随上次」下方有一行短提示。
- 选具体项目会把该档案的电脑一并钉到项目所在电脑（项目只存在于一台电脑上）；之后改电脑会清掉该项目默认、回到「跟随上次」。选「对话」或「跟随上次」不钉电脑。
- 保存后：当前这次新建还没手动改过电脑 / 工作区、且改的是当前来源对应的档案时，立即按新默认重设当前页；否则只对下次打开生效。已经手动换过电脑时不把新默认工作区套到当前页。

## 5. 存储与账号边界

- 默认按登录账号保存在本机（AsyncStorage），不写服务端、不跨手机同步。
- 登出 / 终止会话时清掉该账号这一份；切换账号时各账号保留自己的一份，不串用。
- 新建页原有的「上次选择」记忆继续保留并更新（手动选电脑 / 工作区、创建成功都会写），它只是「跟随上次」的输入，不会被显式默认反向改写。

## 6. 实现入口

- 纯模型与解析：`apps/mobile/src/session/newSessionDefaults.ts`；存储：`newSessionDefaultsStore.ts`；来源参数：`newSessionOrigin.ts`。
- 设置弹窗：`apps/mobile/src/session/NewSessionDefaultsSheet.tsx`（Android 底部 sheet，二级目录浏览复用 device-link 的 `fs:list-dir`）。
- 新建页接线：`app/sessions/new.tsx`；工作区落定：`useNewSessionWorkspace.ts`；组件深链来源：`DesktopEntryHost.tsx`。
- 回归：`newSessionDefaults.test.ts`（解析、回退、项目绑定）、`newSessionWorkspaceEffects.test.tsx`（两份档案、立即生效、手动选择保护）。桌面入口组件的深链白名单仍由 `desktopEntryModel.test.ts` 守护。
- 不涉及原生代码、`app.json` / `app.config.js` 或依赖变化，不触发 runtime fingerprint 冷更。存量装机经 OTA 拿到这次 JS 后，两份档案初始化为原来的「记住上次」，没有可见行为变化；没有桌面入口组件的旧二进制也不会出现组件入口，设置里的组件档案保持跟随应用内。

## 7. 非目标

- 不改桌面端「新建任务」的默认项目规则（见 [项目资料设置](project-settings.md)「桌面新建任务的默认项目」）。
- 不在 iOS 上提供设置入口；不让组件默认覆盖入口明确的目标；不新增服务端同步或跨设备同步。
