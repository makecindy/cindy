# GitHub Star 轻提示

2026-11-09 产品决定：先覆盖桌面端，用户点击后在应用内直接 Star，失败再打开 GitHub。
目标固定为 `makecindy/cindy`，不提供任意仓库写入口。

- 仅桌面主窗口、当前已登录 Cindy 数据账号参与。首次桌面主动发送被接受后至少满 48 小时，
  且之后用户主动发起的一轮任务正常完成，才产生一次展示机会。一天内发送再多也不会提前提醒。
  首次使用时间从功能上线后开始记录，不扫描历史、不用旧发送计数推断天数。
  普通发送、排队与插话共用接受边界；设备互联发送以本端 outbox 接受为准，但接受本身不触发提示。
- 只认实时正常完成事件，并用宿主提供的 `replyToClientId` 匹配本窗口接受的输入；不根据最后一条
  消息、历史回放、状态变为空闲推断完成。取消、失败、静默重试、续跑边界、IM、调度、目标自动运行、
  后台子任务与群内工作均不产生机会。旧版本远端缺少明确来源或输入标识时也不提示。
- 完成后的机会最多保留 5 分钟。允许在刚完成的任务页面或 `/cc-agent/new` 空白新任务页显示，
  不在无关任务、设置或插件页面显示。当前页面无未发送草稿即可，输入框保留焦点本身不阻止提示；
  iframe/webview 内仍不能推断用户是否在编辑，故不展示。计时开始后切页一律取消本次机会。
- 所有已知任务均须无运行、后台工作、发送／插话／排队、待授权／提问／计划审批／插件设置等交互，
  且无未解决错误、凭证切换等待。界面须无可见对话框、错误提示、菜单、其他普通通知或文件传输通知。
  主窗口保持前台并连续安静 60 秒后才检查 GitHub。计时中点击、输入、滚动、焦点变化、切页、新任务、
  新草稿、新通知、失焦或进入后台均放弃本次机会，不重启空闲计时追着用户弹。等待进入首页期间输入／滚动、
  离开到其他页面也放弃；没有赶上本次机会只可能由之后另一次真实成功完成重新获得资格。
- 展示前即时验证当前 GitHub 登录：现有凭证必须通过 `/user` 返回可用账号身份，再查询 Star。
  没有绑定、未登录、登录过期、无权访问或网络状态未知均不提示、不引导登录、不轮询。
  同一控制器生命周期最多查询一次；校验与查询使用同一份凭证。返回时重新检查账号、前台、页面和
  所有打扰条件；迟到结果不得复活取消的机会。已 Star 则记下永久关闭。
- 提示使用现有 Toast 的标题、正文与操作行，固定在右上角、避开标题栏，复用浮层阴影；主按钮使用随深浅色反转的 CTA 样式；文案定为「给 Cindy 点赞」（英文 “Cheer on Cindy”），正文继续明确说明 GitHub Star 操作。加载与成功状态保持同一角落，不参与顶部居中通知的位置动画。无模态遮罩、不抢焦点、不自动消失。
  只允许通知区为空时同步展示，不进入普通通知队列排队。显示前先持久化展示记录，写入失败就不展示；
  已展示后即使直接退出应用或账号恢复重建控制器也不再提醒。“不再提醒”、关闭图标、Star 成功或
  浏览器成功打开仍单独记住关闭选择。
- 点击 Star 才执行 PUT；进行中按钮禁用，成功原位显示感谢，播放一次礼花，并在 5 秒后关闭。
  礼花通过共用的 `ConfettiBurst` 组件实现，基于 canvas-confetti 1.9.4。Star 使用独立参数：160 粒、360° 散布、初速 30、gravity 1.6、ticks 140、origin 取用户点击 Star 的位置（保存视口 CSS 像素坐标，成功后按实际画布尺寸换算；键盘激活用按钮中心），其余使用库默认值（翻滚、摆动、速度衰减与全程淡出）。订阅重置沿用原触发入口，共用动画库但使用单独的小范围上抛参数和原四色。遵循减少动态效果设置，打开网页或失败不播放。
  失败用既有系统浏览器接口打开仓库；浏览器打开失败则保留可重试的链接。
- 使用当前电脑已有的 GitHub CLI 登录，缺失时沿用公开 GitHub 插件的备用 PAT；凭证仅留在 Main。
  远程任务不改用执行电脑的 GitHub 账号。两个无参本机 IPC 不进入 device-link 白名单，拒绝不可信
  frame 与附加参数。账号验证沿用现有 15 秒超时，Star 请求超时 10 秒，不自动重试写请求；请求与显示都隔离账号切换。
- 首次使用时间、展示记录和关闭分别存于 renderer localStorage 的
  `cindy:github-star:<encodeURIComponent(dataOwnerId)>:first-used-at` / `:shown` / `:dismissed`。
  属于当前安装、当前账号的轻量 UI 状态，不存消息内容、凭证，不跨设备同步；清除本地站点数据会重置。
  存储不可用或格式损坏就不提示。展示与关闭状态独立保存，避免记录使用时间时覆盖；其他窗口记录展示或关闭时
  取消本窗口待显示或已显示的提示。不同窗口同时首次发送以最后写入的时间为准，只可能推迟资格，不会提前提醒。

实现：`renderer/lib/githubStarPrompt.ts`、`main/git-context/githubStar.ts`。
点赞成功后的感谢提示固定显示 5 秒后淡出，鼠标悬停或反复移入不暂停、不延长计时；普通通知保留原有悬停暂停行为。
行为验证：同名 unit 测试及 `githubSetupIpc.test.ts`、`toastAction.test.tsx`。
UI 验证：`pnpm ui:check --page github-star --case all --theme all --locale all`，
使用真实 Toast 组件和模拟数据，不代表真实 GitHub 写操作或完整客户端已验收。
