# 邮件卡：阅读、编辑与发送

2026-10-18 至 2026-10-28 的用户裁决汇总。邮件卡由 Cindy 统一实现（卡片、草稿同步、发送与
历史；统一卡片见 #6404，草稿同步与发送修复见 #7607，阅读排版与深色适配见 #7660），邮箱插件
只适配收发能力（契约见插件仓 `docs/mail-compose.md`）；新邮件与回复共用同一张卡。

## 收件人与编辑

- 回复默认「回复所有」，自动排除自己、重复地址和密送。
- HTML 正文直接点进去编辑，保留图文，放大查看时同样可编辑；不设独立编辑模式、源码视图或
  复杂工具栏。附件可添加、查看、删除；草稿可删除。
- 自动同步，没有保存按钮，发送旁没有箭头。To／Cc 同一行按宽度折叠，展开后替换摘要，Bcc 只在
  展开时显示；输入框在标签右侧随内容增高；页脚紧凑并适配手机。
- 同一对话里同一封邮件只显示最新一张卡，旧卡隐藏，不用「草稿已更新」占位；已发送／已删除
  只留最终状态，已发送的卡没有空地址入口。
- 草稿以「上次同步、本地编辑、邮箱里的最新版本」三方合并：版本变化不直接报冲突，各自独立
  的修改自动合并，真正冲突时保留用户的编辑。

## 发送

- 默认展示草稿供确认；只有用户明确确认或已有有效的额外授权才直接发送。
- AI 与按钮共用同一条「发送最新草稿」路径：10 秒倒计时、可撤销、可立即发送；进度显示在
  按钮内，回执回到原任务。

## 阅读

- 浅色模式原样还原邮件：原白底、色彩与排版，信息区与外围共用纯白。
- 深色模式参照 Gmail iPhone：白底与卡片变深灰、文字变浅，彩色背景保留色相并适度压暗，图片
  像素不反色；不再用 92% 深色把彩色压成近黑（2026-10-28 用户对照 Gmail 截图定案，取代此前
  「深浅色都保留原色」的方案）。
- 阅读与编辑的样式分开：阅读不套编辑用的文字包裹与 `pre-wrap`；窄栏尊重邮件自己的响应式
  规则，固定宽度内容仍须可查看。用真实邮件核对配色、对齐与行距，桌面与手机同一套规则。
- 只有用户主动打开或展开才把选中的邮件标记为已读；AI 后台读取与相邻预加载不标记。

## 头像与 Google 权限范围（2026-10-25）

发件人与收件人头像同时支持 Google 联系人照片、公开邮箱头像接口和企业域名图标（参与人头像
见 #7062；Google 联系人部分由插件仓 `google-gmail` 的 PR #222 推进）。为减少日后追加 Google
scope 的审核成本，用户选择一次申请「通讯录管理」：个人联系人的查询／创建／修改／
删除、其他联系人与可见 Workspace 目录的查询、当前账号头像；不包含 Gmail 设置管理。权限与
审核材料按实际功能一一对应准备。这里记录的是范围决定，不代表 Google 已批准 scope 或账号已
重新授权。
