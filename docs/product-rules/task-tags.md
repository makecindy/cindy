# 任务标签

当前实现沿用任务列表单栏结构，不增加标签筛选导航。「任务信息」子菜单提供与时间、PR 状态、worktree、Token、费用同级的「标签」复选项，独立控制列表和卡片中任务信息槽的色球。沿用既有显示偏好持久化与跨窗口同步；「标签」排在「时间」之前，默认两项均勾选，多标签色球重叠显示。已有自定义显示项保持原选择。标签在信息区单独保留色球，鼠标悬停任务或操作按钮浮出时仍显示，与按钮并排；每个色球悬停显示对应的本地化标签名称。其他任务信息继续让位并释放原占用宽度。显示开关不修改标签关联；任务状态标识保持原语义。

任务菜单在常规操作与归档／删除之间显示排序靠前的标签。最多七个标签，同行最后一个圆形「…」进入完整编辑器。桌面菜单悬停色球时放大色球、上方与气泡均提示添加或移除标签；选中状态用球内勾选标记，悬停已选球显示叉号，未选中的悬停球显示加号。统一标签面板可增删当前任务的标签、创建标签、改名、换色和删除标签，不再拆分「标签」与「标签设置」。桌面拖动行排序，点击色球或名称勾选，双击名称或点击悬停编辑按钮修改名称和颜色；手机长按手柄后标签行跟随手指移动，其余行让位，松手吸附后保存排序；支持边缘自动滚动与系统减少动态效果设置。点击名称选择，点击常显编辑按钮编辑。键盘可在排序手柄上使用上下箭头，手机提供辅助功能增减操作。标签目录最多 256 项，单任务最多 32 个标签；颜色为红、橙、黄、绿、蓝、紫、灰、粉、珊瑚、青、靛蓝、白共十二色。名称最长 80 字符，持久名称去除首尾空白后忽略大小写判重。预置名称的界面翻译不占用自定义名称；自定义标签保持独立身份，不按翻译后的显示名合并或拒绝。旧无颜色标签按白色显示，旧请求仍被接受并在保存时归一白色。白色球用细边框和固定深色勾。桌面与手机列表最多展示十二行，并随窗口可用高度收缩；列表溢出时滚动条常显，标题与添加入口留在滚动区域外。手机任务列表中的色球仅展示，不弹出名称菜单；任务标题栏色球可打开任务详情。详情和任务菜单的标题居中，下方完整显示当前标签的色球与名称；任务详情的标签管理在独立弹窗中打开，关闭即完成选择，无额外完成按钮。快捷标签支持长按查看名称，末尾「…」与色球同尺寸。任务色球外圈跟随行背景及选中状态。默认只显示列表，点击添加或编辑后在同一面板切换为名称与两行六列色板，取消不写入，保存后返回列表；不显示双击编辑提示。

首次获得标签功能的账号预置十二个标签：前六个为「红／橙／黄／绿／蓝／紫」颜色标签，后六个为「重要／待跟进／工作／生活／灵感／资料」，后六个分别使用珊瑚／粉／靛蓝／青／白／灰，与前六种默认色红／橙／黄／绿／蓝／紫不重复。默认名称随界面语言显示，用户改名后显示自定义名称。预置项与普通标签一样可改名、换色、排序和删除，不自动关联任务；已有标签目录保持不变，用户删掉的标签不会在重启后补回。显式补入预置项沿用创建接口的 `presetId`，仅接受已知预置 ID 及其标准名称和颜色，追加到目录末尾；ID 已存在则拒绝覆盖。预置名称覆盖简体中文、繁体中文、英语、日语、韩语，桌面和手机按各自界面语言显示同一标签。

取消任务上的标签只解除关联。删除整个标签前显示影响任务数量，包含归档任务；删除不影响任务或消息。预览后目标标签或其任务关联变化会使删除失效，必须重新核对；其他标签的变化不影响本次删除的对象与影响范围。

## 数据与跨端

标签目录和关联位于承载任务的电脑、当前账号的数据库。SSH 工作目录不改变标签的归属；远程桌面和手机通过现有 device-link 通道操作来源电脑。不按名字合并不同电脑的标签。

目录排序保存在来源电脑，新增标签追加末尾，改名换色保留位置。排序操作提交完整新旧顺序，目录已变化时拒绝覆盖；新排序字段兼容旧客户端字段，旧数据按原顺序迁移。

界面和 AI 共用命名数据库事务。关联增删只改变指定标签，不覆盖其他标签。来源电脑写入后推送任务标签；目录改动单次推送有界目录，由各端更新已加载的任务色球，不按全库任务数广播。手机任务列表冷缓存保存经过校验的任务标签；标签目录另外使用按账号、设备隔离的内存缓存，先展示缓存再后台校准，退出账号或设备不可访问时清除。打开的标签面板同步其他端的任务勾选变化；断线重连后主动重读目录和关联，旧连接或旧请求结果不覆盖新状态。断线可查看缓存，但不能写入；旧主机不支持新通道时按结构化错误码识别，保留其他任务操作并显示简洁更新说明，不显示空色板或无效的更多入口。读取失败与保存失败分开提示，读取失败提供重试；iOS 菜单中的标签区域跟随原生容器宽度，不按错误文字的固有宽度收缩。

新增 `local-db:task-tags:execute` invoke 和 `local-db:task-tags:changed` push；推送归 `sessions` topic。调用沿用 owner 与远程伙伴可见性检查。仅增加协议能力；旧主机未知通道不可视为成功，旧控制端可忽略新增标签字段。响应可选 `supportedColors` 宣告主机色板；缺失时只允许原七色，新色禁用并提示升级。旧控制端无法识别新色，需要升级后才能完整显示新色标签。没有服务端或原生依赖变更。

## AI 工具

通过现有 `cindy_helper` 的渐进发现入口暴露：`list_task_tags`、`get_task_tags`、`find_tasks_by_tag`、`create_task_tag`、`update_task_tag`、`reorder_task_tags`、`add_task_tags`、`remove_task_tags`、`delete_task_tag`。查询属于 history，写入属于 control。没有当前任务身份或受限制的伙伴调用不可管理账号标签。

工具以当前任务所在电脑为来源，跨任务操作传明确 ID。全局删除先返回数量及短期确认 token；用户明确确认后才能执行，token 绑定调用任务、标签和预览版本，不替代用户授权。不会自动给用户任务分类。

## 视觉与验证边界

色球是用户选择的分类标记，使用独立 `task-tag-*` 语义角色，不能复用运行状态颜色。色球本体和「…」均为圆形；输入框及文字按钮沿用控件圆角，编辑窗口沿用容器圆角。Desktop 与 Mobile 各自颜色真相源同时覆盖 Light／Dark，保留用户主题覆盖。

数据库使用新增 migration，不改历史 migration。开发验证仅使用独立 profile。运行截图、测试结果和未覆盖平台在交付报告中单独说明；HTML 原型不算实际应用验证。
