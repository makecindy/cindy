## 规范、兼容与回滚

Toast 短通知保留 pill；实际消息或动作换行时按内容容器取 12px，依据用户以 Cindy 实際 UI 效果优先的本轮指令。所有状态色、默认时长与调用接口保留。模型菜单归一8px/12px，普通按钮几何、发送40%透明度、MCP内层圆角及公开字号别名保留。`send-btn-disabled-*` 未删除或强行接入。

新增 `form-field-hint` 默认转发 `text-secondary-mid`；外部主题导入模板不扩展、已有主题文件不改写，用户可显式覆盖新帮助角色。命名 Tailwind 色只新增 candidate report，不扩大阻断范围。

本批可按视觉/交互消费者及对应 Token 源与生成输出整体 revert；不涉及协议、数据库、系统提示词或用户数据迁移。G2 独立非设计师试用仍未发生，Mobile 设计系统完整迁移仍为后续阶段。
