## Caveat recorded, not papered over

The cancelled turn's assistant row is stamped `turnCompleted: true`. The desktop's generic
terminal path (`apps/desktop/src/main/maker-ipc/sessionEventTerminal.ts`) treats any non-Codex
`done` event as successful — the `raw.status === 'completed'` / `cancelled !== true` predicate in
`isSuccessfulCodexDoneEventData` is applied to the Codex source only. So the agent's
`done status:'cancelled'` is carried in memory but not persisted as a distinct state: the row says
"completed", not "cancelled".

This is harmless for Hermes specifically — the Hermes translator only emits `tool_use` /
`tool_result`, never `update_plan`, so the plan-capsule history-recovery risk that the Codex
predicate exists to prevent cannot arise. It is nonetheless a gap in the persisted model, recorded
in ROADMAP Debt for whenever a non-Codex agent needs a distinguishable cancelled state.
