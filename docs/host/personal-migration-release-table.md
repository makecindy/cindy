# 个人版迁移放行表

2026-11-12 起，随 M1 每个检查点更新（分支 `cindy/host-m1`，检查点标签 `m1-cp*`）。
个人版切到 Host 之前，「个人版应保留的能力」必须逐项有结论；本表记录每项的现状与证据。
开放迁移由交接任务决定，本表只提供依据。

状态口径：

- **已对齐**：Host 与桌面用同一份代码或等价逻辑，这条能力的写入、落盘、清理都已接上，有不带界面的自动验证；真实验证另列。只接了一部分时写「部分」，并列出没接的调用点。
- **部分**：只对齐了一部分，缺口写在同一行。
- **未做**：写明排在哪一步。
- **移出 M1**：写明移到哪个里程碑和原因。

拆分桌面模块与在 Host 上接用放在同一个检查点，不为「将来会用」先拆。

「自动验证」都是不带界面的测试；「真实验证」指真实账号、打包产物或带界面运行，M1 内均为「无」，
除非另行写明。

### Windows 持久子代理的系统空目录（已验证）

rc9 在发布提交 `ce58e49a47` 上的 27 项 CI 全部通过。Windows 的独立对照证实：父进程监视启动 PowerShell 时，系统会在全新的 `USERPROFILE` 下创建空的 `AppData\Roaming` 目录骨架；runner 与只执行一次 PowerShell 空命令的对照目录集合相同，没有文件、链接或其他条目。临时缓存仍在重定向的临时目录。真实用户目录通常已有这些系统目录，没有可见影响；生产的父进程监视方式本轮不改。Windows 上同步启动 PowerShell 的成本留到引擎二进制管理前评估。
