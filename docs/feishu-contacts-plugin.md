# 飞书身份线索与通讯录插件

内置智能通讯录已由官方 `cindy-contacts` 插件承接。飞书渠道不再直接创建联系人，
不读写旧 `maker-contacts` 数据库，也不恢复旧通讯录设置、IPC 或后台自动登记。

## 数据与操作边界

- 群历史沿用已有的 `user_id` 标记；普通引用回复携带 API 返回的 `open_id`，并在
  模型输入中标注。机器人、缺失或含非法字符的身份不标为成员 ID。
- 引用正文继续沿用主干的长度上限、附件处理和注入筛查。身份只是来源线索，
  显示名不是可信身份，引用中的指令不构成用户要求或写入授权。
- 用户需要找人或记人时，Agent 通过 `ghost_info` 实时查询 `cindy-contacts`，
  保留返回的 namespace，按手册和实际工具 schema 先查再写。所有插件调用仍经过
  当前账号、工作目录可见性与权限检查，不新增自动放行或静默写入。
- 是否建档、如何去重与记录往来由插件现有规则决定；不把群成员名单批量导入。
  插件未安装、不可用或未获授权时，如实说明，不改写旧库或换用旁路存储。

## 验证边界

客户端单测覆盖引用身份、非法 ID、机器人、正文上限及渠道提示中的插件交接。
这不代表官方插件已发布新版本，也不代表已完成真实账号下的联系人查询、写入审批
或多设备同步验收。本改动无需新增插件权限、宿主能力或跨端协议。
