# 在飞书中使用 Cindy

Cindy 官方商店应用把飞书连接到你自己的 Cindy 工作电脑。你可以私聊机器人，或在群里
@ Cindy 交办任务，进度、结果和需要确认的操作会回到飞书。

## 1. 安装 Cindy 和飞书应用

先从 [Cindy 官网](https://cindy.cn/download) 下载桌面客户端，登录你的 Cindy 账号，
配置可用的模型与工作目录，并保持工作电脑在线。Cindy 软件开源，模型服务的使用条件
及费用以所选服务提供方为准。

在飞书切换到准备使用的企业，从 [飞书应用中心](https://app.feishu.cn/) 查找 **Cindy**，
核对应用名称和开发者信息，按页面提示获取或申请获取。是否需要管理员审批，以企业
规则和安装页面为准。应用尚未公开开放安装时，测试企业中的可用状态不代表其他企业
也能安装。

官方商店应用由 Cindy 维护，不需要你创建飞书应用，也不需要填写 App Secret 等凭据。

## 2. 管理员确认权限和成员范围

飞书企业管理员在 [飞书管理后台](https://feishu.cn/admin) 的「工作台 → 应用管理」中
找到 Cindy，检查已安装版本的应用权限以及可用成员、禁用成员。需要审批的申请到
「工作台 → 应用审核」处理；申请规则可在「应用管理 → 设置管理规则」中查看。

如果你的 Cindy 账号由组织管理，Cindy 组织管理员也需要在 Console 的飞书机器人设置中
允许使用官方应用。Cindy 的组织开关、飞书企业安装授权和个人账号关联是不同的步骤；
开启其中一项不会代替另外两项。

## 3. 关联你自己的飞书账号

在 Cindy 桌面端设置的「IM 机器人」中找到官方飞书 / Lark 机器人，点击关联，按页面
提示使用正确企业中的飞书账号完成授权。不要把关联码、账号凭据发给其他人。

回到飞书，按应用详情中的机器人名称搜索 Cindy 并打开私聊。确认接收任务的工作电脑
在线；可以从机器人菜单的工作区入口查看或选择工作电脑。

## 4. 私聊或在群里 @ Cindy

私聊可以直接发送任务，例如：

> 请根据当前项目的公开示例资料，整理一份待办清单。

群聊需要先把机器人加入目标群：在飞书电脑端进入「··· → 设置 → 群机器人 → 添加机器人」，
搜索并添加 Cindy，再 **@ Cindy** 发送任务。若群设置限制添加，请联系群主或群管理员。
企业安装应用、个人关联账号都不会自动把机器人拉进群。

任务由你选定的 Cindy 工作电脑执行。你可以在飞书中查看进度和结果；遇到需要确认的
操作时，阅读交互卡片后再决定。机器人还提供任务、工作区和帮助菜单，具体项目以
当前版本显示为准。

## 消息权限用于什么

- 单聊消息用于接收你交办的任务。
- 群内 @ 消息及已获授权的群消息用于理解请求、引用内容和相关上下文。
- 群信息用于识别任务来源，图片与文件资源用于处理消息附件。
- 发送、更新消息和表情用于反馈进度、结果与操作确认。

读取群聊上下文需要相应的群消息权限，机器人也必须已加入目标群。安装应用不会自动
授权机器人读取全企业的所有群聊。请只在你有权处理的群和资料中使用。

## 遇到问题

| 情况 | 下一步 |
| --- | --- |
| 应用中心找不到 Cindy | 确认当前飞书企业，以及应用是否已开放安装。 |
| 安装申请待审批 | 在飞书查看申请进度，请企业管理员处理。 |
| 企业已安装，自己无法使用 | 请管理员检查可用成员、禁用成员和当前企业身份。 |
| 提示权限不足 | 请管理员核对已安装版本的权限；重新关联个人账号不会补齐企业授权。 |
| 群里无法添加机器人 | 先确认本人可用，再检查群设置并联系群主或群管理员。 |
| 机器人提示电脑离线 | 启动对应电脑上的 Cindy 并保持联网，恢复后再发一次任务。 |

使用反馈可发送到 [feedback@cindy.app](mailto:feedback@cindy.app)，或通过
[Cindy 使用支持](../SUPPORT.md) 提交问题。公开反馈中不要附带真实聊天、文件、关联码或密钥。
