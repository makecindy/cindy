# 供应商详情：紧凑摘要与统一滚动

打开 [交互设计稿](./index.html) 查看已确认的布局方向。页面自包含，所有数据均为模拟值，品牌图标为占位符，不连接真实账号。

- 供应商身份固定；用量摘要和模型一起滚动。
- 模型搜索与筛选工具栏到达滚动区顶部后吸顶。
- 具体重置日期与趋势按需展开，余额和告警保持可见。
- 支持深浅色、矮窗口、搜索与模型开关演示。

这是设计参考，不是运行中的客户端。客户端保留原有管理菜单、显示/停用语义、模型分组、定价标记和供应商专属操作；不采用设计稿中的简化批量按钮。

## 客户端验证边界

实际 `ProvidersSection` / `UnifiedModelList` / `QuotaHoverCard` 的渲染结果使用模拟账号和模型在 Chromium 中检查过深浅色与矮窗口：身份留在滚动区外，工具栏吸顶，用量和模型共用滚动位置。此验证不涵盖 Electron 登录、网络刷新或真实账号操作。

组件回归覆盖多个供应商适配器、模型深链、多配额窗口、明细展开/收起、余额、限额告警和过期数据提示。
