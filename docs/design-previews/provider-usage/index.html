这版改了什么

  • 和「设置 → 用量」同一套：右上筛选、概览数字、近 30 天每日柱图、活跃热力图、按模型表，样式和交互（悬停看明细、点柱子或格子选那一天）照搬。
  • 多电脑：默认看合计。「组内电脑」下拉可以只看一台；新增「按电脑」表，每台用了多少、几个人在用一眼看到。
  • 每日柱图可切换按人 / 按电脑 / 按模型堆叠，柱子高度就是当天总量。
  • 按人：原来的人列表变成和「按 Agent」一样的表；分享状态、加入时间、最近使用和 ···（关闭／恢复、删除）仍在这一行。点一行 = 只看这个人，整页跟着变，代替原来的“展开看每台电脑”。
  • 没有组时：不出现「组内电脑」下拉、「按电脑」表和“用到的电脑”，其余一样。
