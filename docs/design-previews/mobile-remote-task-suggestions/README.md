# 移动端远程任务引导：HTML 证据

[下载并在浏览器打开 index.html](./index.html)。页面为单文件，不依赖服务、账号或外部资源。

这是 PR #4414 中 `129508571` 的界面还原快照，基于用户已确认的 HTML，补齐后续审查修复的文案和空态浮动按钮显隐。推荐文案、规则和颜色来自 Mobile 源码；实现正本仍在 `apps/mobile`，此页面不参与 App 构建。

- 左侧切换 0、1、3、4、8 条任务、筛选后 3 条、无结果、折叠、离线和同步中。
- 支持 Light / Dark 和五种语言；查看列表底部推荐、换一组、点击预填、编辑与模拟发送。
- 完整空态只保留一个新建主按钮。模板点击只预填，模拟发送也不会连接真实设备。
- 设备、项目、任务和模型均为样例；搜索筛选菜单与新建页外围控件为 HTML 近似，不能作为原生导航、键盘或系统菜单验证。
