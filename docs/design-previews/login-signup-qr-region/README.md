# 注册前确认、扫码登录与跨版本切换：交互原型

`index.html` 是实现前（2026-11-26）绘制的可点击原型，覆盖 Desktop 与 Mobile 的完整登录流程：
账号不存在时先确认再注册、两个方向的扫码登录、电脑与手机版本不一致时的切换提示。直接用浏览器
打开即可，不依赖构建。

现行规范以 [`login-flow.md` §16.4](../../design-rules/login-flow.md#164-登录链路逐屏) 与
[区域规则 §2.4](../../product-rules/region-and-editions.md#24-区域是构建期维度不是用户可选项)
为准；协议见 [`auth-signup-qr-login.md`](../../dev-rules/protocol-compatibility/auth-signup-qr-login.md)。
实现与原型的差异：

- 扫码登录只有一个方向（2026-11-27 定）：电脑已登录，在侧栏「远程控制 Cindy」弹窗显示二维码；
  手机在「还没有 Cindy 账号」里点「扫码登录」扫码认领，电脑点「允许」后手机登录同一个账号。
  原型里「手机扫码登录电脑」那一套（电脑登录页出码、电脑「还没有 Cindy 账号」里的扫码行、
  手机首页「扫一扫」确认电脑登录、电脑端询问切换版本）没有实现。
- 电脑与手机版本不同时，只在手机上询问是否切换版本。
- 验证码屏主按钮文案为「继续」。
