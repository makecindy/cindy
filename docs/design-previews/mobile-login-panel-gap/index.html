③ 窄屏分支 dh<1334：三种落位公式 vs 被压缩后的字标底

纵轴 = stage 设计px，横轴 = designHeight。 面板顶（loginY）落到字标底之下即发生遮挡（不透明面板盖住字标）。 被否的 dh-712（红）在 dh∈[600,1222] 全段位于字标底之下 —— 这正是评审实算否掉它的依据（dh=1000 处压 40 设计px）；采纳的钳制式（黄虚线）与 main 的 dh-640（蓝）在 dh<1262 完全重合（窄屏行为与 main 逐值一致）， 自 dh=1262 起钳在 622 不再上移，并在 dh→1334⁻ 与短屏档连续。 左端 dh<822 处字标底高于三条落位线 = 字标本就与面板交叠（main 既有行为，本 PR 未恶化）。
