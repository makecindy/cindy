# 供应商分享：交互设计稿

打开 [交互设计稿](./index.html) 查看供应商分享的界面方案。页面自包含，所有账号、用量与链接都是模拟数据，品牌图标为占位符，不连接真实账号或设备。

产品规则正本见 [`docs/product-rules/provider-sharing.md`](../../product-rules/provider-sharing.md)。

六个场景：

1. **设置入口**：「允许被远程调用」一行开关左侧的「管理分享」图标；可切换「全部开启／供应商未开放／未开远程控制」三种能力状态，看不可点击时的提示。
2. **管理页**：待处理（待审批申请）、已分享的人、按模型的用量（近 7 天／本月／全部），关闭／恢复／删除均可点击演示。
3. **生成链接**：一次性链接、5 分钟倒计时与重新生成。
4. **受邀者申请**：确认申请（含身份展示说明）、等待同意（显示配对码）、已同意、链接已失效（已被使用或已过期）四种弹窗状态。
5. **分享者审批**：只显示申请人的昵称和头像，以及同一个配对码供核对；同意分享／拒绝申请。
6. **受邀者模型列表**：分享来的供应商与同账号远程供应商的标题对比，以及已暂停、分享者离线两种不可用状态。

支持浅色与深色切换。这是设计参考，不是运行中的客户端，也不代表 Electron 实机验收。
