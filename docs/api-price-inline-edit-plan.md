# 模型报价行内编辑（PR #8722）

## 目标和边界

沿用模型高级设置的原布局，把「编辑 API 估价」入口改为直接编辑报价数字，并在报价标题旁提供「重置」。
只调整 Desktop renderer 的价格交互、对应翻译与回归测试；图片输入、协议、上下文、引擎能力与其它设置原样保留。
不修改 main/preload、IPC、价格计算、历史用量、真实账单、权限或持久化格式。

## 实现

- `ModelPriceOverrideDialog` 复用原读／写／重置接口，增加 inline 呈现；其它调用方式保留。
- `ModelAdvancedDrawer` 的可编辑报价区域使用 inline 呈现。XD、组织管理及付费锁定模型沿用只读报价。
- 保留引擎及可用币种选择；价格按当前引擎／模型读取与保存。复杂价目、折扣、单位和说明放在「参考价详情」中，跟随选中引擎。
- 打开、聚焦或未改变的失焦不写入。有效价格在失焦时调用原保存接口；Enter 保持焦点、不提交；`0` 合法。
- 输入／输出为空、负数、非有限数或非十进制数字时沿用错误提示，并恢复对应字段之前的有效值；不保存为 `0`。缓存字段空值沿用原可选语义。
- 没有参考价时用 `—` 区分未知与零；首次建立报价等待输入、输出均填写后验证。
- 遵循 DESIGN.md §14.2–14.3：首次 Esc 离开价格字段并按失焦保存，不提示「已撤销当前输入」；保存结束后再按 Esc 才关闭外层设置。
- 同目标报价广播在空闲时刷新；保存／重置期间排队，结算后读取最新值并保留失败草稿。未保存字段与新报价按字段合并，待刷新时先读取最新值再提交，不覆盖其它窗口改动的未编辑字段。币种变化不猜测换算。
- 保存中字段只读并保留焦点；切换引擎等待保存成功后进行，失败保留原引擎和有效草稿。阻止在保存／重置中关闭或通过底部动作卸载设置。
- 重置删除当前报价 override，重新跟随参考价；不把参考价写成静态 override。编辑后第一次点击重置优先执行重置。
- 说明缩短为「仅用于估算你的 API 或订阅通道用量，不会改变供应商的实际账单。」；「参考价更新于 …」独占下一行。

## 设计与验证

遵循 `docs/design-rules/DESIGN.md` §3 字号、§4 标准 Button／SegmentedControl、§5 圆角、§10 语义主题、§14 焦点与键盘。
沿用原设置行、分隔线、字号和颜色 token，同时实现 Light／Dark；不引入新设计 token 或基础组件。

组件回归覆盖：保存 payload、空值恢复、合法零、非法数字、Esc、重置、引擎切换、异步迟到响应、焦点及外层关闭保护。
复用 `model-advanced` 单页场景，验证真实组件的两种主题、各语言、标准与窄宽布局；宿主读写为内存模拟，不作为实际持久化或打包验收证据。
提交前执行 Desktop typecheck、根 `pnpm test:unit:related`、i18n／设计门禁，并检查完整 diff 不包含图片输入或其它业务改动。

## 自审

- 修改入口与原读写协议相同；重置仍删除 override，未自定义用户继续跟随默认参考价。
- 不重算历史金额，不改变 token 统计、供应商扣费或模型运行行为。
- 新 PR 内容从最新主干重建；不带入旧分支的图片输入修改和验收图片。
