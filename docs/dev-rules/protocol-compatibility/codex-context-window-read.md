# 远程 Codex 原生上下文窗口只读查询

> 通用规则与 Review 清单见[跨端协议兼容](../protocol-compatibility.md)；本文件只记录这一项能力的协议约定。

`maker:model-context-limit:get` 增量进入同账号已授权设备的 invoke 白名单，复用原有结构化
`{ agent, providerId, modelId, sessionId? }` 查询与数值响应。只读模型偏好和 `codexContext`
（总窗口、可用窗口、自动压缩阈值、原生来源等），不返回 CLI 配置正文、路径或凭证，不开放设置写入。
本机仍须可信顶层 Renderer；远程以 Main 的调用上下文确认同账号 owner，分享/访客不获此能力。

有 `sessionId` 时读取执行端同一活任务的原生窗口；任务缺失、模型/显式来源不匹配或读取期间
任务/路由变化返回未知，不退回该电脑的其他任务或默认配置。不带任务 ID 的模型选择浮层
读取目标电脑该模型的原生配置预览，不能用该预览代替任务的实际窗口。
账号变化、撤权、断链及目标失效沿用现有 owner/peer 代次，迟到结果作废。

旧被控端返回 `CHANNEL_NOT_ALLOWED`，或原生窗口/方法缺失时展示未知；不读控制端配置，
不以 catalog、最大容量、任务预算或可调档位猜算。旧控制端不调用，原有行为不变。
查询使用既有后台调度名额，无新轮询、重试、订阅 topic 或恢复连接动作。

不改变 relay 帧、kind、签名、鉴权或隧道封装；官方/自建中转均原样转发业务 channel，
无需同步修改服务端或升级已部署中转。Mobile 可继续使用既有通道；没有新增原生依赖或冷更。
