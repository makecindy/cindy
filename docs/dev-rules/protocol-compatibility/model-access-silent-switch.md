# Model Access 静默切换引擎

> 通用规则见[跨端协议兼容](../protocol-compatibility.md)。

Pi 和 Codex 运行时准备就绪后，桌面在 V5 目录请求的 `X-Cindy-Model-Capabilities` 中声明 `silent_switch`。如果冷启动先拿到兼容目录，引擎就绪时复用现有同步补拉一次。Model Access 只为声明该能力的组织成员读取成员覆盖。旧服务端返回原有目录，新客户端接受没有 `silentSwitch` 的响应。

每个任务在进程重启或新会话后，由第一条读到当前权威目录的发送判定一次：桌面从权威目录中读取当前 Cindy AI 模型。该条目以 `silentSwitch: true` 提供唯一可用引擎时，已有任务可进入发送流程，由主进程在发送锁内校验目标的协议、运行时和连接后交接。目录尚未权威（同步在途或失败）时本次不判定，切换可能在之后某条发送发生，历史照常交接。交接期间目录刷新只要该条目仍指向同一目标就继续；切换失败记日志后在原引擎继续发送，本次进程内不再重试。发送中、已登记手动切换、跨设备和协同任务沿用各自的发送路径。字段缺失、关闭或目标不唯一时使用原有选择逻辑。
