# 插件嵌入本机服务页面

`mainView.localServiceUrl` 是可选 Desktop 字段。两个 manifest 校验入口对新包要求
`http://127.0.0.1:<显式非默认端口>/<路径>` 的规范形式，不接受凭证、查询串或片段。
旧存量数据保留历史原值。插件继续提供 `mainView.html`，旧 Host 和未获得此项批准的安装照常读取它。

本机安装或更新对话框展示完整 URL。新 receipt 的 `approvedLocalServiceUrl` 只记录经本机对话框
明确批准的地址。服务端默认安装、远程批准、历史 manifest 和历史 receipt 不产生此项批准。
同实例更新仅延续相同地址的批准，移除声明或更换安装来源不会沿用旧批准。旧 Host
可以忽略新增 receipt 字段。回滚无需迁移。

本机页面使用独立的内存 Electron session，分区绑定账号、物理插件实例和批准代次。
仅受信桌面窗口可申请嵌入。Main 校验插件已启用、实例与完整入口一致并持有对应批准。
宿主限制 HTTP 文档、资源和 WebSocket 的请求地址，拒绝变更协议或端口、弹窗、下载及
浏览器权限请求。承载分区的代理配置不继承系统代理，页面禁用 Web Worker 和 Service Worker。账号切换、失效的批准与插件停用销毁 guest。网页无 Node、宿主桥、目录或自动启动服务。
支持页面沿用主视图默认放置、主题 token 和颜色模式。未增加移动端呈现、远程 IPC 或共享数据协议。
