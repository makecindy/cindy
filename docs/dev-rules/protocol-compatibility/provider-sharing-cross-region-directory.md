# 跨区供应商分享名单的只读核验

- 官方跨区服务在已有的会话响应中可选声明 `directoryReadSupported: true`。仅此声明允许客户端向签发凭证的区域发送 `POST /x/directory`；完整请求、认证和权威名单语义见[供应商分享契约 §6.2](../../provider-sharing-contract.md)。
- 先部署只读服务并验证不会轮换凭证或关闭正在运行的 relay，再声明支持。旧客户端忽略可选字段；新客户端遇到旧服务保留原凭证周期，不试探新接口。仅适用于官方跨区连接，不向自建中转或其他区域转发凭证。
- 接受标准：经过原 30 分钟展示期限后，授权的来源仍在新任务中，原连接和凭证不变；失败不续期，权威空名单移除来源。客户端回归入口是 `providerShareCrossRegion.test.ts`，服务端上线前还须进行长任务联调。
