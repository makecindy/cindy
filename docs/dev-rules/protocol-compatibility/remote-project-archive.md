# 远程项目批量归档

本机项目通过 preload 查询本机库，SSH 项目还限定原主机。本机和跨设备项目使用同一套成员查询和归档事务。
跨设备时，桌面控制端向项目所属设备调用同账号 Device Link 通道
`local-db:sessions:project-archive`。请求携带项目目录、动作 `archive` 或
`unarchive` 及阶段。自建中转沿用现有加密 invoke 信封，无新增 relay 消息类型。

- `preview` 由被控端按普通任务可见范围和项目目录（含托管 worktree）查询，无侧栏分页上限。
  每项返回任务 ID、worktree 标记和跳过原因。控制端用项目名、设备名及数量请求确认。
- `apply` 只带一个已确认的任务 ID。被控端在任务路由锁内复核项目、任务状态及运行情况，
  状态事务同时校验项目路径、置顶和接管情况。确认期间新增的任务不进入这一批。
- 旧被控端拒绝新通道时提示检查连接与版本。控制端不使用本机库或无条件远程写入兜底。
  连接中断后重新操作会先生成新预览。

桌面端从 Cindy 移除本机项目时，勾选归档会通过本机 preload 使用 `archiveOnRemoval`。
状态写入前，宿主会将关联工作目录的回收策略持久化为保留。Device Link 和 SSH 项目拒绝这个动作。
