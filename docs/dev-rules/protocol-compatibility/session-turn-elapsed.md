# 桌面任务状态栏的本轮耗时

Desktop 和独立 Host 在单条 `local-db:sessions:get` 的结果中附带可选的
`turnElapsedMs`。执行端使用现有 `activeTurnStartedAt` 标识本轮，以开始、收尾标记计算
毫秒数。运行中按读取时刻采样，已收尾时返回固定差值；缺少开始记录或已经清空时返回 null。
列表和批量读取不附带实时采样。

桌面控制端按设备、任务和本轮绑定读回的样本，在前台用单调时钟走秒。打开、重连、
唤醒和轮次结束时重新读取。旧执行端可省略字段，此时隐藏耗时；旧控制端忽略新增字段。
沿用已有加密隧道和读取权限，支持混合版本，无需更新中转。

正常收尾的结束标记在本轮已完成时保留首次完成时刻，后续空闲回收或重复终态不会拉长耗时。
用户显式确认旧中断继续沿用原有 MAX 更新。隐藏文档或宿主窗口时停止读取及重试，
恢复显示后补读，多个恢复事件共用同一在飞读取。
