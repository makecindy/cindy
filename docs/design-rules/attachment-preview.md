# 附件预览视觉与交互

依据 `DESIGN.md` §2 语义颜色、§3 字体、§4 Buttons / Dialog & Modal、§5 布局，以及 `design-governance.md` §13 点击目标。此文补充附件预览的固定结构，不创建另一套主题。

## Desktop

顶部 64px：左侧文件名与简短信息，右侧保存、更多、关闭；图标 16px、热区 32px、圆形按钮。底部为类型工具栏，图片顺序是缩小、比例、放大、适应、标注；已有集合在工具栏旁显示上一项 / 计数 / 下一项。工具栏不跟着内容缩放。文档使用主题表面，媒体保留媒体画布，标题与控件有独立背景。

## iOS / Android

顶栏为安全区加 64px：左侧关闭、居中文件名、右侧更多；图标 20px、热区至少 48px。底部类型工具与附件集合分行，保持窄屏可点。系统播放器负责媒体控件，宿主负责退出与文件操作。横屏按实际可用区域计算，不能直接缩小一张竖屏截图。

## 还原要求

图片/视频保持固有比例，PDF 初始完整适应可用区域。文件名一行省略，完整名称在更多面板可读；长标题不能压扁关闭键。工具栏不悬浮遮住文本首行，不随手势滑出视口。颜色来自当前主题，不为某张原型写死主题。

多语言使用已有术语和翻译资源；只有实有能力显示动作，禁用动作有相应可访问性状态。共享操作与专用内容不互相覆盖。关闭不能兼任移除待发附件。
