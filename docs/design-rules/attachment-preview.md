# 附件预览视觉与交互

依据 `DESIGN.md` §2 语义颜色、§3 字体、§4 Buttons / Dialog & Modal、§5 布局，以及 `design-governance.md` §13 点击目标。此文补充附件预览的固定结构，不创建另一套主题。

## 呈现方式（用户定稿 2026-11-03）

Desktop 与手机分别贴合各自平台：Desktop 预览浮在原界面之上，手机（含 iPad）全屏并沿用内置浏览器的浮动玻璃按钮。各查看器只换外壳，内容与操作不变。

- **Desktop**：遮罩用弹窗同款 `.modal-scrim`，点窗外即关闭。预览窗距窗口四边 40px，最宽 1440px 并水平居中；12px 圆角、Board 描边、`--shadow-menu`。顶部 40px 是窗口标题栏（mac 红绿灯、拖动窗口），预览窗从它下面开始。遮罩整层 no-drag，盖掉主界面顶栏的拖拽区（Electron 只按几何命中，不看层级，否则会吞掉关闭键的点击），顶部 40px 再声明为拖拽区。几何与组件见 `PreviewChrome.tsx` 的 `PREVIEW_PANEL_STYLE` / `PreviewScrim`。
- **Desktop 打不开的文件**（压缩包等，只有文件信息和「在系统中打开 / 显示所在文件夹」）用同一外观的居中小窗（480×360），不占大窗；「显示所在文件夹」在访达 / 资源管理器里选中该文件。
- **iOS / Android（含 iPad）**：全屏，外壳与内置浏览器同一做法。顶部是浮动的玻璃圆钮「关闭」、玻璃胶囊文件名（宽屏限宽 560pt 居中）、玻璃圆钮「更多」；顶栏不画底色与分隔线。文件详情收进「更多」，「更多」用系统下拉菜单（没有系统菜单的旧包退回底部面板）。底部类型工具、查看器自带工具行（页码、缩放、查找、换行等）与附件集合各成一枚玻璃胶囊，居中浮在页面上。iOS 26+ 用系统 Liquid Glass，其它环境退回 `surfaceElevated` 实色圆角底加 Board 描边。查看器内容区不自带底色，跟随宿主页面，避免透明顶栏下露出接缝。组件见 `apps/mobile/src/session/PreviewChrome.tsx` 的 `PreviewGlass` / `PreviewToolbar`。

## Desktop

顶部 64px：左侧文件名与简短信息，右侧保存、更多、关闭；图标 16px、热区 32px、圆形按钮。底部为类型工具栏，图片顺序是缩小、比例、放大、适应、标注；已有集合在工具栏旁显示上一项 / 计数 / 下一项。工具栏不跟着内容缩放。文档使用主题表面，媒体保留媒体画布，标题与控件有独立背景。

## iOS / Android

顶栏为安全区加 64px：左侧关闭、居中文件名、右侧更多（均为浮动玻璃按钮，见上节）；图标 20px、热区至少 48px。底部类型工具与附件集合分行，保持窄屏可点。系统播放器负责媒体控件，宿主负责退出与文件操作。横屏按实际可用区域计算，不能直接缩小一张竖屏截图。

## 还原要求

图片/视频保持固有比例。Desktop 文件浏览及复用 `FileBodyView` / `PdfPreview` 的 PDF 预览，初次打开与切换文件默认适应宽度，优先保证窄面板的文字可读性；宽而矮的面板允许纵向滚动，不承诺初始整页可见。独立的「适应页面」按钮按正文区可用宽高完整显示单页；两种适应模式都随容器尺寸变化重算，手动缩放保持用户选择的倍率。iOS / Android PDF 仍初始完整适应可用区域。此项 Desktop 默认行为由 [PR #8448](https://github.com/makecindy/cindy/pull/8448) 的宽度自适应范围更新，取代此前跨端统一的初始整页适应要求；验证范围见[补充记录](../design-evidence/2026-11-01/attachment-preview/README.md#pr-8448-desktop-pdf-宽度自适应2026-11-02)。

文件名一行省略，完整名称在更多面板可读；长标题不能压扁关闭键。工具栏不悬浮遮住文本首行，不随手势滑出视口。颜色来自当前主题，不为某张原型写死主题。

多语言使用已有术语和翻译资源；只有实有能力显示动作，禁用动作有相应可访问性状态。共享操作与专用内容不互相覆盖。关闭不能兼任移除待发附件。
