# 用量历史图表与日期选择

适用入口：设置 → 用量历史（`UsageHistorySection`）；2026-10-17 起供应商「远程与分享」页的用量复用同一套（见文末）。依据为 2026-09-07 所有者圆角裁决与 `DESIGN.md §5`；`usage-heatmap-day` / `usage-token-bar` 的成员登记与 2026-09-08 交互几何登记由本 PR 直接落在 `DESIGN.md §4/§5`（usage data marks 2px 例外 + 交互几何段），不依赖尚未合入的规范 PR。

## 可见层与布局

| 可见角色 | 半径依据 | 尺寸与数据映射 |
| --- | --- | --- |
| 热力图日格 | §5 成员 `usage-heatmap-day` | 可见格 12×12px，行列间隔 3px。金额/Token 口径、分位色阶、日期窗口算法沿用组件原逻辑；静止形状和网格密度不随点击启用与否改变；09-08 登记的交互强调见下。滚动视口内预留 3px 外围空间，容纳边缘指示器。 |
| 每日 Token 柱 | §5 成员 `usage-token-bar` | 固定近 30 天、柱间隔 3px，均分可用绘图区宽度；不设每柱 24px 最小宽度或 807px 容器下限。非零高度按原比例计算、最低 3px；零值日保留 2px 高。总量、日期 tooltip 与纵轴刻度保留；模型分段按下述 09-09 裁决覆盖完整模型，tooltip 按实际模型列出（样式见下「每日柱图悬停浮层」）。 |

柱体自身的裁剪采用同一登记处理。按钮的透明命中层不裁剪数据图元，不继承 pill 外形；键盘按钮语义、可访问日期/用量名称和 `aria-pressed` 保留。非交互渲染分支仍不创建按钮，其格子遵守同一成员登记。

## 设备范围（2026-09-26 所有者需求）

用量历史默认合并同账号所有电脑的用量，时间范围选择器左侧增加设备选择器：所有设备（默认）/ 本机 / 其它电脑。外观、尺寸与时间范围选择器一致（36px 胶囊触发器、同一下拉菜单样式；按 `DESIGN.md §4` 面板与触发器等宽，长设备名截断、状态说明在面板内换行），选项下方以 12px tertiary 文字注明其它电脑的「数据截至」时间或读不到的原因（离线、未允许远程控制、需要更新 Cindy、读取失败）。其它电脑只列出读到过用量的（有「数据截至」），从未读到的不显示；没有这样的电脑时不显示选择器。进入页面后第一次读取其它电脑期间，控件下方显示一行 12px tertiary 的小 spinner +「正在读取其它设备的用量…」，之后每分钟的后台同步不再提示。合并视图里有电脑读不到最新数据时，控件下方显示一行 12px tertiary 提示。「最耗 token 的任务」按所选时间范围统计每个任务在该范围内产生的 token（每日 × 任务记录，从功能上线起积累；所选范围早于最早记录时副标题注明「按天统计从 X 起」），多设备范围合并其它电脑的任务并在任务名下方用 12px tertiary 标出设备名。任务标题、模型与删除状态取当前值：页面打开期间重命名或删除任务会随即反映，不等下一次用量变化。任务标题是跳转到该任务的链接，整行是鼠标的放大命中区（hover 使用 `--surface-hover`）；其它电脑的任务仅在该设备已连接、能找到对应任务时可点击。各设备的用量按其本地日期计（记录只精确到天，无法按小时换算）；其它电脑已跨入本机「明天」时，超出本机今天的部分计入本机今天，避免今日合计和图表漏掉。读取其它电脑走后台链路，对方不会显示「正在被控制」横幅；0.1.93 及更早版本的电脑不去读取，状态为「需要更新 Cindy」。切换账号时设备选择回到「所有设备」，不保留上一个账号的设备列表。热力图、柱图、表格与配色规则不因设备范围改变。

## 每日柱图悬停浮层（2026-09-26 所有者要求）

所有者认为原生 title 提示「不好看、没有设计感」，每日 token 柱图改用自绘浮层 `UsageBarsTooltip`，热力图仍保留原生 title。整张图共用一个浮层实例。悬停与键盘聚焦是两个独立触发源，任一仍有效即显示（悬停优先）；指针离开绘图区且没有聚焦柱子、或失焦且没有悬停时收起。滚动、窗口尺寸变化与数据刷新时按当前布局重新测量并跟随柱子。

| 层 | 规格 |
| --- | --- |
| 容器 | `--tooltip-bg` / `--tooltip-text`（两模式同为深底白字，沿用共享 Tooltip），12px 圆角、`--shadow-menu` 投影加 10% `--tooltip-text` 发丝内描边（Dark 下与卡片底色区分），内边距 12×10px，宽 220–320px（不超过视口宽度减去两侧 8px 边距） |
| 头部 | 日期（含星期，11px，60% 不透明度）；当日总量 16px / 500 等宽数字，单位 11px 弱化 |
| 占比条 | 4px 高、2px 圆角的横向分段，颜色与柱段相同，按 token 降序，段间 1px 间隔；与明细同口径只画前 6 个模型，其余合成一段 40% 不透明度的中性段，不会因模型多而被裁掉 |
| 明细 | 8×8px、2px 圆角色块 · 模型名（截断）· token（500，等宽右对齐）· 占比（50% 不透明度）；按 token 降序，最多 6 行，其余折叠为「另有 N 个模型」 |
| 位置与动效 | portal + fixed，优先置于绘图区上方，空间不足翻到下方，上下都放不下（如 3× 缩放的矮窗口）时夹在视口内、超出视口高度的部分截掉（头部日期与总量始终可见），水平以柱子为中心并夹在视口内；入场 `animate-fade-in`，在柱子之间以 `--motion-fast` 平滑跟随，首次定位与减少动态效果时不过渡 |

浮层 `aria-hidden`：柱子按钮的 `aria-label` 给出日期与总量，逐模型明细经 `aria-describedby` 指向同组件内的 `sr-only` 文本，承接原生 title 的信息。色块与占比条沿用 `usage-token-bar` 的 2px 数据图元角，不是新的形状登记。

## 页面排版（2026-09-08 所有者反馈）

用量历史对齐其他设置页面的阅读层级，沿用 `DESIGN.md §3` 的现有字号 Token，不修改全局字号或共享首页排版：

| 作用层 | 字号 / 字重 |
| --- | --- |
| 页面标题 | 16px / 500 |
| 卡片分区标题 | 14px / 500 |
| 页面说明、时间范围、表格正文 | 13px / 400；范围标签、模型/Agent/任务名称为 500 |
| 表头、统计标签、分区副标题 | 12px；表头为 500，其余 400 |
| 概览数值 | 16px / 500（试用反馈后由 20px 下调），长值允许换行，不以省略号隐藏 |
| 图表月份/纵轴刻度、引擎标签、刷新提示 | 11px / 400 |

表头和统计标签使用 secondary 文字色，提高阅读清晰度。月份行高与纵轴宽度随字号缩放；表格沿用数字右对齐与等宽数字，长名称保留既有截断和完整名称提示。日期筛选、图表窗口、颜色和选中动效不由本次排版调整改变。

## 配色（2026-09-09 所有者扩展裁决）

热力图继续使用蓝色四档强度映射，零值日为 `--surface-chip`，高值色为 `--usage-heatmap-high`。

模型表的每个模型及其柱图片段均有分类颜色，不再只给前五名上色，也不把其余真实模型合并成灰色“其它”。身份仍为 agentKind × 完整模型名，不合并展示名相似的模型。完整历史按 token 排序建立统一 colorOrder；切换日期范围、选择单日、表格排序变化均不重新分配颜色。只在历史日期出现、最近 30 天未使用的模型也包括在内。刷新后完整历史的用量排名变化可以改变配色，这不是永久的模型品牌色。

前五个颜色继续使用 `--usage-model-1` … `--usage-model-5`（青绿、珊瑚红、紫、靛蓝、琥珀）。此后每组五个从对应 Token 派生 OKLCH 色相：第 g 组旋转 `(g × 137.50776405) mod 360` 度，保留源色的亮度和色度，由浏览器处理显示色域。值随活动主题解析，不写死 Light/Dark 色号，也不改写用户主题。派生算法唯一实现在 `usageHistoryColors.ts`，属于治理合同 §3.4 的运行时派生值；不为每个模型建立 Token。没有数量上限导致的灰色回退；只有调用方缺失登记的异常兜底仍为中性“其它”。大量模型可能有近似色，颜色不承诺无限的感知可区分性，名称、harness 标签与 tooltip 继续辅助识别。

Agent/harness 表复用现有引擎身份色（09-09 所有者再次反馈）：claude-code → `--engine-badge-cc`（陶土橙），codex → `--engine-badge-codex`（蓝），pi → `--usage-model-1`（青绿，试用后替代不易与蓝色区分的紫色）。顶部占比条、行前色块和行内占比短条三处一致，不随 Agent 用量排名变化。Claude / Codex 与应用内既有品牌标识一致；pi 按所有者选择使用青绿色，不声称是官方品牌色。Claude / Codex Token 按既有合同跨 Light/Dark 固定值，pi 使用既有青绿的 Light/Dark 值；均表示身份而非成功/警告状态。任务排行、首页金额看板、文字和控件仍沿用既有中性色；本裁决不登记新形状、不改变几何、动效、日期功能或数值口径。

## 点击、焦点与选中（2026-09-08 更新）

- 用户明确选择“悬停微弹，选中保持”。**本段替代 09-07 对这两个成员一概不缩放的限制**，仅登记下列状态几何；基础圆角、数据映射及命中规则保留。
- 热力图从 12×12px 平滑扩大到 14×14px，中心不动；柱体只增加 2px 宽度，高度、基线及各模型分段高度不变。进入曲线只有一次轻微超调，扩张总量小于 3px 间隙。直接调整可见层的宽/高而非整体 scale，确保**四角在动画中仍为 2px**。
- 进入/聚焦/选中使用 `--motion-base`（200ms）与组件专属 `--usage-mark-ease: cubic-bezier(0.2, 0.8, 0.25, 1.18)`；退出使用 `--motion-fast`（150ms）与 `--motion-ease-out`。同一已选中图元再次悬停不重复弹跳；选中后移开指针仍保持放大。禁止循环动画，不移动其他图元。
- 命中框始终保持原尺寸：热力图 12×12px，柱图高度 `max(24px, 柱高)`、宽度按可用空间均分。放大的可见层和指示层均 `pointer-events: none`，不把相邻日期的命中区叠在一起。
- **热力图选中描边（所有者最新试用反馈）**：选中格保留 14×14px 放大，在独立指示层画 1px `--text-primary` 描边，距离放大后的格子 1px；Light 为深色、Dark 为浅色。指示层随放大后的尺寸定位，不覆盖蓝色数据填充，不扩大点击范围。只应用于选中格，普通 hover 不加此描边。
- **柱图仍不加鼠标选中外框**。单日位于柱图 30 天窗口内时突出该日；选择“最近 7 天”时突出含今天在内的最近七个日历日，包含零用量日，只改变视觉强调，不把七根柱标为七个单日选中。单日选择优先于范围强调。选中日超出柱图窗口时，柱图没有选中或强调的日期，所有柱恢复正常显示。默认最近 30 天及所有时间同样无单日选中。
- 有上述强调日期时，其他柱保留 **60% 不透明度**（替代此前 24%），选中/范围内柱、临时悬停与键盘聚焦柱保持全色。柱高、基线、类别色 Token 与堆叠比例不变；**热力图强度不参与淡化**。范围强调不触发七根柱同时放大，也不改变固定 30 天数据窗口或概览/明细筛选逻辑。
- 键盘焦点仍使用独立的 2px `--focus-ring` 轮廓（偏移 1px），仅 `:focus-visible` 显示；热力图聚焦时覆盖中性选中描边，不叠画两圈。无阴影。
- `prefers-reduced-motion: reduce` 时不播放过渡，立即落到对应大小与清晰的焦点/选中状态；触摸设备不依赖 hover，禁用柱不触发强调。
- 原生 Enter/Space 点击继续使用原 `handleDayClick` → `day:YYYY-MM-DD` 筛选路径。图表继续显示固定窗口，概览和明细按所选日期过滤；单日模式下任务明细的既有隐藏规则不变。

## 日期入口与命中方案

09-08 曾按所有者决定移除草稿 `UsageDateFilter`（“选择日期＋查看当天”）入口，保留预设与图表按日点击。DS-11（2026-09-15，N8）按所有者授权补回等价的任意日期入口：范围下拉旁新增带标签的标准 `Input type="date"`（36px 高），与图表按日点击共用同一条 `day:YYYY-MM-DD` 选日状态——输入与图表互相同步，清空回到最近 30 天，以 todayKey 为上限拒绝未来日期，日期基准未就绪时禁用输入。原生日期弹层外观由系统浏览器决定；亮暗浏览器验证（未加载→加载→未来拒绝→选中）见 [DS-11 证据](../design-evidence/2026-09-15/ds11-review-fixes.md)。原有所有时间、最近 30 天、最近 7 天、今天预设与图表按日点击保留；图表仍不新增点击空白取消或重复点击取消。

图表标记自身的命中几何裁决不变：命中框保持已登记尺寸（热力图 12×12px、柱图高度 `max(24px, 柱高)`），数据标记不因等价入口的补回放大或缩小。等价入口补回关闭的是此前登记的“欠交付等价入口”缺口；真实平台与用户侧验收仍须独立记录，台账在记录补齐前不标记 migrated，也不据此声称已满足原定 Equivalent 条件或批准 Essential 豁免。日期行为测试验证的是选日状态同步与筛选路径，不是点击尺寸合规证明。

## 「远程与分享」页的用量（2026-10-17 所有者确认原型）

供应商「远程与分享」页的「用量」块复用本页的图表与表格，规则见 [供应商组](../product-rules/provider-groups.md) §7：

- **同一套组件**：热力图(`UsageHeatmap`，token 口径)与每日柱图(`UsageSeriesBars`，`UsageTokenBars` 的通用形态，几何、交互、浮层、
  淡化与选中规则完全相同)；卡片、概览数字格、表格列样式(`UsageBreakdownTables` 导出的表头/单元格/色块/占比格)与筛选下拉
  (`UsageFilterSelect`，与时间范围、设备选择器同一外观)都与本页一致；整块套 `.usage-history-charts`。
- **标题与筛选同一行**(2026-10-17 用户反馈文字多、排版怪后收紧)：块标题「用量」(13px / 500) 在左，筛选组在右——使用方与组内电脑
  168px、时间范围 148px 的 36px 胶囊下拉，与 148px 日期输入(只有 `aria-label`，不另写「日期」)，间距 8px；放不下时筛选组整组换行、
  靠左，不出现右对齐后左侧大片空白。标题下不放说明文字，也不另写「正在看 X」(下拉与选中行已表达)。时间范围与本页相同；那台电脑
  是旧版本、只有所有时间合计时，不摆出时间范围与日期，筛选下方一行 12px tertiary 写需要更新；两张图不显示。
- **柱图分色可切换**：按人 / 按电脑 / 按模型(卡片标题行右侧 28px 分段控件，不另写副标题)。人、电脑与模型三类都用本页登记的
  分类色(`DESIGN.md §2` 2026-10-17 扩展)：人按表里的顺序、电脑按组里的顺序、模型按完整历史用量排名；时间范围与筛选变化不重新
  分配颜色。当时没有区分电脑的「更早的记录」作为最后一类。
- **卡片顺序**（2026-10-19 所有者要求）：概览、活跃热力图、明细、近 30 天每日 token；热力图紧接概览。
- **明细单卡**（2026-10-19 所有者要求）：热力图之后、每日柱图之前只保留一张明细卡，标题行左侧用共享分段控件切换按人 / 按电脑 / 按模型，
  默认按人；没有组时不提供按电脑。控件为 28px 轨道 / 24px 选项，使用 `tablist` / `tab` / `tabpanel` 语义，右侧沿用范围副标题。
  切换只改变表格视图，保留当前使用方、电脑与日期筛选。
- **表格**：三种视图沿用本页按 Agent / 按模型表的列样式与占比条；按人与按电脑两张表的一行可点(整行是鼠标的
  放大命中区，名字是带 `aria-pressed` 的按钮供键盘使用)，选中行用 `--surface-chip` 底色；分享的人一行行尾 `···` 与下方的转分享
  列表不属于点选区域。
- **已移出电脑**（2026-10-19 所有者要求）：电脑下拉与按电脑明细只列当前组内电脑，移出后不再单列旧电脑；
  历史用量继续计入概览、按人、按模型与图表，在按电脑明细里合进「更早的记录」。
- 双模式：只用语义 token 与本页登记的分类色，Light / Dark 同一实现。
