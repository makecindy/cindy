# 桌面伙伴与群列表状态

2026-11-03 最新裁决：只调整状态点与收起选中态，其余 UI 对齐 main。

展开列表的全部几何以及收起头像本身的尺寸与构成沿用 main，不新增群类型图标，展开态状态点保留已确认的行尾位置，收起态在头像右下角；有状态时显示状态点，无状态时显示时间，原时间列宽度与布局保留。用户随后单独确认收起头像条可以缩小横向间距：36px 头像不变，点击区 40px、间距 4px；不影响展开列表或状态点尺寸。收起选中态用圆形外描边（1px、留空 2px）替代底板。

收起头像状态点沿用 main 的 10px 彩色核心与 2px 背景色边缘，总直径 14px。展开行尾状态点与 Session 相同：8px 彩色核心、16px 居中槽，不带背景描边。未读和完成未读为绿点，进行中为橙色呼吸，待处理青、报错红；错误优先。移除 @ 与未读数字的重复提示，保留原有时间列布局。选中不改变状态色，真实读位清除未读，执行状态不因选择消失。

Mobile、Session 不变；浅色和深色使用语义 token。

展开列表进行中只保留原有 Thinking／正在输入等摘要提示，行尾不再显示橙色点；收起头像仍显示橙色呼吸点，其他状态不变。
