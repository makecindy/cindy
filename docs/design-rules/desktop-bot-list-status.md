# 桌面伙伴与群列表状态

2026-11-04 确认版本：只调整状态点与收起选中态，其余 UI 对齐 main。

展开列表的全部几何以及收起头像本身的尺寸与构成沿用 main，不新增群类型图标，展开态状态点保留已确认的行尾位置，收起态在头像右下角；展开时保留时间，状态点或未读数字放在时间下方；原时间列宽度与行高保留。用户随后单独确认收起头像条可以缩小横向间距：36px 头像不变，点击区 40px、间距 4px；不影响展开列表或状态点尺寸。收起选中态用圆形外描边（1px、留空 2px）替代底板。

收起头像状态点沿用 main 的 10px 彩色核心与 2px 背景色边缘，总直径 14px。展开行尾状态点与 Session 相同：8px 彩色核心、16px 居中槽，不带背景描边。Bot 私聊的未读和完成未读为绿点，不显示条数。群普通未读在展开行尾复用侧边栏 NavigationCountBadge 灰色数字徽标（最多 99+），收起不显示点；群未读且提到本人时显示蓝点，不显示 @ 字符。进行中为橙色呼吸，待处理青、报错红；执行状态优先于消息提醒，错误优先。保留原有时间列布局。选中不改变状态色，真实读位清除未读，执行状态不因选择消失。

Mobile、Session 不变；浅色和深色使用语义 token。

展开列表进行中只保留原有 Thinking／正在输入等摘要提示，行尾不再显示橙色点；收起头像仍显示橙色呼吸点，其他状态不变。

多电脑合并的 Cindy 行在当前电脑空闲、其他电脑运行时，摘要显示运行电脑的名称与处理状态；当前电脑也在运行时仍优先展示当前电脑。运行结束后恢复当前电脑的消息摘要，不切换设备选择或打开目标，也不补回行尾橙点。

当前边界：现有群摘要的 `serverUnread.mentioned` 只标识显式提到本人。未带提及标记的“Bot 回复本人”尚无独立摘要字段，本轮没有将所有 Bot 发言误判为回复本人；该部分需要另行补齐消息关系判定。
