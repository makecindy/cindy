# 桌面伙伴与群列表状态

2026-11-04 确认版本。仅调整 Desktop 伙伴与群列表；Mobile、Session、群话题和悬浮提示不变。颜色使用语义 token，同时支持浅色与深色。

## 几何与选中态

- 头像沿用 main：收起 36px、展开 44px，群头像构成不变，不新增群类型图标。
- 收起点击区 40px、间距 4px；选中为 1px 圆形外描边，留空 2px。`+N` 圆形保持 36px。
- 收起状态点锚定头像右下角：10px 彩色核心、2px 背景色边缘，总直径 14px。
- 展开行与任务列表模式的一条任务同高（随界面字号缩放），行间 2px、圆角 8px；选中沿用任务行的实色底、文字色与 1px 内描边，群头像叠层描边随选中底色。行高与选中样式和任务行共用 `cc-agent/sidebar/listRowStyle.ts`（2026-11-06 用户裁决，取代 10-29 的淡色选中）。时间列与摘要布局不变。状态点／数字位于时间下方，与第二行摘要垂直居中；状态点为 8px 核心、16px 居中槽，无描边。不得按整行底部固定定位。

## 状态规则

| 情况 | 展开 | 收起 |
| --- | --- | --- |
| Bot 私聊完成未读或普通未读 | 绿点，无数字 | 绿点 |
| 群 Bot 完成且有未读，未提到本人 | 仅绿点 | 绿点 |
| 群普通未读，无完成记录，未提到本人 | 灰色数字 | 蓝点 |
| 群未读中提到本人，无需优先展示的执行状态 | 蓝色数字 | 蓝点 |
| Bot 或群正在工作，无未读 | 橙色进度文字与呼吸星星，无行尾橙点 | 橙色呼吸点 |
| 群正在工作，同时有未读（包括提到本人） | 橙色进度文字与灰色数字 | 橙色呼吸点 |
| 等待处理／报错 | 青点／红点，无数字 | 青点／红点 |
| 消息读完且无工作需要关注 | 无提示 | 无提示 |

- 优先级沿用线上共享规则：待处理（青）→ 报错（红）→ 进行中 → 完成未读 → 普通未读 → 空闲。单条目、多电脑 Cindy 与 `+N` 复用同一规则；隐藏群的绿／蓝点参与 `+N` 汇总。
- 群数字复用 `NavigationCountBadge`（最多 `99+`）。蓝色数字使用 `--bot-unread-bg`／`--bot-unread-fg`，显示群未读总数，不是提及次数。不显示 `@` 字符。
- 展开私聊进度覆盖本机 Bot、独立远程 Bot、多电脑 Cindy，复用群的 11px 呼吸星星与橙色文字；结束后恢复原消息摘要。
- 选中不改变状态色，不等于已读；真实读位清除未读，执行状态不因选择而消失。

## 多电脑与数据边界

- 合并 Cindy 行在当前电脑空闲、其他电脑运行时，摘要显示运行电脑名称与进度；当前电脑也运行时优先展示当前电脑。远程仅有运行快照时仍显示处理进度。结束后恢复当前电脑摘要，不切换设备或打开目标。
- 合并行展开后的完成／未读提示属于当前电脑。电脑选择菜单与「近况」电脑列表保留 main 原有蓝色未读提示及数字规则，数据来源与显示条件不变。
- 群摘要 `serverUnread.mentioned` 仅表示显式提到本人；尚无独立字段识别“Bot 回复本人”。不能把所有 Bot 发言当作回复本人。
