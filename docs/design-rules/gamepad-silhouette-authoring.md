# 手柄线稿交稿约定

设置页里的手柄图不是插画，是 **可点的键位图**：用户点某一块，改这个键绑定什么；按下真手柄时，对应块会亮。

本文以当前 Xbox Series 图为合格样板。新手柄按同一套交，不要另发明一种画法。

- 线稿现稿（可直接打开）：[`xbox-series-gamepad.silhouette.svg`](./xbox-series-gamepad.silhouette.svg)
- 代码实现：`apps/desktop/src/renderer/components/settings/XboxGamepadLayout.tsx`

---

## 1. 要交什么

最小包三样，缺一不算齐：

1. **分层 SVG**（主交付）
2. **参考线稿 PNG**（和画板同尺寸，或注明缩放）
3. **键位表**（每个可点部件的 id、热区、填充、备注）

不要只交照片、自动描边、或一张打平的 AI/PNG。

---

## 2. 画板与坐标

沿用 Xbox 这套网格，方便直接写进代码：

| 项 | 值 |
|---|---|
| 画板 | `1050 × 660` |
| 显示 `viewBox` | `(0, 0, 1050, 660)` |
| 单位 | **图上 1px = 代码 1 单位** |
| 朝向 | 正视，握把朝下，左摇杆在左上、右摇杆在右下（Xbox 布局） |

量点时直接读 SVG / 参考图像素。左右对称的手柄，先定中线（Xbox 约为 `x = 525`），右半用 `x' = 2 × 中线 − x`。

SVG 根节点写明：

```xml
<svg viewBox="0 0 1050 660" fill="none"
     stroke="currentColor" stroke-width="2.6"
     stroke-linejoin="round" stroke-linecap="round">
```

颜色用 `currentColor`，不要写死黑白。外壳轮廓可以 `stroke-width="3"`，内部零件保持 `2.6`。

---

## 3. 线怎么画

- **少量长立方贝塞尔（`C`）一气呵成。** 外壳两侧、握把、肩键弧，各用几根长曲线，不要沿像素描成上百个短段。
- 锚点落在结构转折上：喇叭顶、肩线与机身相接、握把最外、分界竖线。
- 需要轻微弧度就画浅弧，不要为了「精确贴图」把线折碎。
- 两条线在视觉上是一根贯通线时，端点必须对齐到同一坐标（例如肩键三根横线与分界竖线交于同一 `x`）。
- 线和机身相接时，端点落在外壳 path 上，不要悬空、也不要为了贴边去改已经定稿的键位线。该收的是外壳，不是键。

禁止：

- 位图描边、自动 trace
- 把按钮轮廓画进外壳（见 §5）
- 用一块闭合色块代替「一根键的几条边」

---

## 4. 图层：一根线只属于一个东西

先分清 **外壳 / 按键 / 装饰**，再下笔。这是 Xbox 返工最多的地方。

| 层 | 画什么 | 不画什么 |
|---|---|---|
| `body` | 外壳外轮廓、喇叭外形、握把 | 肩键顶边、扳机内沿接到台面的那段 |
| 扳机 `lt` / `rt` | 喇叭本身；需要时加喇叭内侧短刻线 | 肩键上缘 |
| 肩键 `lb` / `rb` | 这颗键自己的每一条边 | 画进喇叭里面、或跟外壳抢同一段 |
| 台面 / 中线 | 键与键之间共用的横线、竖分界 | 和外壳轮廓重复描一遍（外壳已有的台面线，键的线接到它即可） |
| 摇杆 / 十字键 / 面键 / View / Menu / Guide | 各自零件 | — |
| `decor` | Logo、配对灯、Share 空胶囊等 | 不要做热区 |

**肩键这种「一块塑料、多条棱」的，一条棱一根 path。**  
Xbox 的 LB 是三根线，接到中间三根横线：

| 肩键上的线 | 接到中间 |
|---|---|
| 较高的上缘弧 | 最上面那根（台面 / `y ≈ 154`） |
| 较低的上缘弧 | 中间那根（`y ≈ 172`） |
| 底边 | 最下面那根（`y ≈ 188`） |

两根上缘弧形状相似，都画在肩键上，**都不进 LT**。底边左右可以略低于中间，但两端要落到外壳上。分界处三根横线与竖线对齐到同一 `x`（现用 `437` / `733`）。

扳机（LT）和肩键（LB）不要共用一段轮廓。喇叭内沿接到台面的那条，算肩键最上沿，不算扳机。

---

## 5. 可点部件与热区

每个能改绑定的键都要有热区。热区是叠在图上的透明按钮，不是描边的一部分。

### 必须有热区的（Xbox）

`lt` `rt` `lb` `rb` `xbox` `view` `menu`  
`y` `x` `b` `a`  
`left` `right`（摇杆）  
`dpadUp` `dpadDown` `dpadLeft` `dpadRight`

Share、配对灯、装饰刻线：**无热区**。

### 热区怎么标

矩形：`[x, y, w, h]`（与画板同一坐标）。圆的加 `round`。不规则的（扳机喇叭）**直接交闭合 path**，热区和按下填充用同一条，不要另画一个方块再裁切。

Xbox 扳机现用：热区 = `press-lt` / `press-rt` 同一 path。灰块必须贴满喇叭边，不能和外壳之间漏缝，也不能盖到 LB。

### 键位表格式

```json
{
  "id": "lb",
  "hit": [205, 152, 232, 52],
  "round": false,
  "press": "#press-lb",
  "notes": "三根边接到中间三根横线；热区顶边在喇叭下方，不要伸进 LT"
}
```

摇杆额外给：

- `center`：`[x, y]`
- 凹槽椭圆、帽的圆
- 模拟量移动半径（Xbox 现用约 `14`）

---

## 6. 按下填充

每个可点键另出 **闭合 path**（`Z`），只用于半透明填充，不负责描边。

- 填充形状贴着该键可见范围，不要漏到外壳外或邻键上
- 描边仍用 §4 那些分开的线，不要靠填充的边当轮廓
- 填充色由实现写成 `currentColor` + 低透明度，稿里用灰色示意即可

扳机填充跟着喇叭，且与热区同一 path；肩键填充是三根线围起来的口袋。灰块若和外壳之间有缝，把填充沿贴到外壳那条弧上。

## 8. 交稿 SVG 检查

打开 SVG 应能直接回答：

- [ ] `viewBox` 是 `(0, 0, 1050, 660)` 或已换算到这套
- [ ] 外壳是少数长弧，没有碎锚点
- [ ] 每个可点键的边都在自己的图层，没有画进外壳
- [ ] 肩键若有多条棱，每条单独 path，并写明接到哪根中线
- [ ] 贯通线在分界处端点重合
- [ ] 与外壳相接的线，端点在外壳上
- [ ] 每个可点键有 `hit` 和 `press`，热区不互相大面积重叠
- [ ] 装饰件标明「无热区」
- [ ] 描边未写死颜色，用 `currentColor`

---

## 9. 常见不合格

1. **自动描图**：轮廓一顿一顿的，两侧对不齐。退回重画长弧。
2. **键的线画进外壳**：看起来像扳机多了一条内沿。把这段改到对应键的图层。
3. **少线**：肩键只画了一条边，中间横线接不上。按零件真实棱数补线。
4. **热区是个大方块**：点 LT 点到 LB。不规则键用零件自己的闭合 path 做热区。
5. **按下灰块和轮廓之间有缝**：灰块没贴到外壳。填充左/右沿要走外壳那条弧。
6. **为了贴边去改已经定稿的键位线**：该动的是外壳，不是键。
7. **结构差很多的手柄**（DualSense、Switch Pro）：先交分层线稿草图，确认「哪根线算谁的」，再收最终 SVG。

---

## 10. 给同事的一句话

> 先打开旁边那张 Xbox SVG 对照。交一套同网格的分层 SVG：长弧、按键与外壳分家、多棱键一条棱一根线、热区和按下填充用同一闭合 path。不要描像素，不要把键画进壳里。
