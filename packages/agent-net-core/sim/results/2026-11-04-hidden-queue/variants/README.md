# 没留下的版本

这几个版本的代码没有归档，只留矩阵原始结果，给上一级 README 里“试过但没留下”的数字作证据。
命令同最终版（`compare` 带 `AGENT_NET_KCP=none AGENT_NET_NO_CPU=1`，`share` 用 `SHARE_MODE=full`，定时器 1 微秒或 1 毫秒），都是三个种子。
带“诊断”的行是上一级 README 里那几种带随机丢包的多连接场景，当时临时加在 `share` 里，最终版没有。

| 文件前缀 | 和最终版的区别 |
| --- | --- |
| `by-packet-count-` | 第一版只收回补偿：两个阶段的包按个数累计（降速样本攒到 1024 个减半），标准误按每个包独立算，判断一撤销补偿每轮放开 1/64；不清理估计、不改限速门槛 |
| `per-cycle-mean-` | 每个周期单独算“巡航减降速”，平滑这个差值，标准误按周期之间的差别算；其余同上 |
| `hold-band-` | 和最终版差两处：差别在门槛和 1.5 个百分点之间时补偿保持不动；低于 1.5 个点才放开，每轮放开 1/64，不按时间换算 |
| `no-dispersion-` | 最终版去掉周期之间的离散修正，标准误只按每个包独立算 |
