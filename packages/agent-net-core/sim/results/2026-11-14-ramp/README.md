# 一阵数据开头一个往返内量出线路速度（2026-11-14）

核心指纹 `2a0f11441af7`（算法同上一轮），逐文件见 `source-sha256.json`。与
[`2026-11-14-auto-window`](../2026-11-14-auto-window/README.md) 相比改了 `src/congestion.rs`、`src/connection.rs`、
`sim/tests/bursts.rs`、`sim/mutants.py`。环境同上一轮，核心 `[dependencies]` 仍为空，线格式不变。

用户 2026-11-14 的要求：Agent-Net 要在速度和稳定性上全面超过原来的 Device Link，不再出现消息拥堵。上一轮的端到端对比里，
往返长、带宽高的线路差距最大：跨地区（50 Mbit/s、往返 200 毫秒）上 1 MiB 要 1.3 秒，原来 0.47 秒
（[`benchmarks/agent-net-session-2026-11-13`](../../../../../docs/benchmarks/agent-net-session-2026-11-13/README.md)「自动窗口后全面对比」）。
模拟器里同样的线路（`exp/exp_ramp.rs` 的「bench far」）第一阵 1.1 秒，和压测一致。

## 原来的问题

1. **只发过小消息的连接比新连接起步还慢。** 两端平时只有零星小消息，带宽估计停在小消息的速度（每秒约 2 KB），按它算的窗口
   落到最小窗口（16 个分片，约 22 KB），比新连接的初始窗口（64 个分片）还小。新连接第一批包按每秒 16 MB 快发、用确认间隔
   一步量出速度（`train_rate`）；只发过小消息的连接没有这一步，一阵数据每个往返只涨不到三倍，往返 200 毫秒的线路上要爬五六轮。
2. **小消息的副本被当成排着的数据。** 丢过包以后，小消息会多发一份副本保底；发原件时副本还排着，这个包被当成满负荷发出的，
   它的确认算成满负荷的一轮。停下来时每条零星消息都在挤掉旧的带宽估计，十条以后之前测到的速度就没了。改动前的核心上，
   家宽 100 Mbit/s、往返 32 毫秒的线路停 5 秒后那一阵从 67% 掉到 17%。

## 做法

1. **一阵开头那一串快发量速**（`Bbr::on_sent`、`train_rate`）。还没在应用有数据排着时测过路径（只见过零星小消息），
   又来了一阵数据（排着的数据至少够一个初始窗口），开头一个初始窗口按新连接第一批包的方式快发，窗口这一串期间至少是初始窗口；
   确认到达时按确认间隔量速度。连续写零星小消息不算一阵：那时每条都马上发走，快发一串只会冲爆窄带线路的队列。
   这一串一个往返后还没量出来（丢得太多），下一阵重新来一串。
2. **量出瓶颈以后不再按启动的倍数冲**（`train_found_bottleneck`）。那一串的确认明显比发得慢（低于发送速度的八成），
   说明包在瓶颈前排着队，确认间隔就是瓶颈的速度：这时不封顶，之后在启动阶段按它的 1.25 倍发；测到比它快四分之一以上，
   说明量低了，回到启动的倍数。一阵数据往往几个往返就发完，启动阶段结束不了，按启动的倍数（约 2.9 倍）发的话每一阵都一下冲过队列。
   令牌桶、配额这类不排队的限速器放行的包确认和发的一样快，量出来是发送速度，照旧按原来的上限（每秒 4 MB）封顶。
3. **小消息的副本不算排着的数据**（`connection.rs` 的 `app_limited` 只看重传和流里的数据）。

新连接的第一批包、Lean 以外的策略差别、窗口和缓冲都不变。

- **全量变异还没跑完**：2026-11-14 机器同时有别的负载，6 个分片一小时只跑了 29 条（全部抓到、没有漏网），照这个速度要五六个小时，
  会占满 CPU、让端到端压测失真，先停了。提交前在空闲的机器上补跑全量，结果写回这里。

`exp/exp_chunked.rs` 是之后查端到端分块传输时加的实验：只跑核心的「请求一块、回 512 KiB、同时 4 块在途」，家宽线路 85%、
跨地区 52%、每秒 1 MB 线路 98%，用来确认分块传输慢不在核心（[端到端记录](../../../../../docs/benchmarks/agent-net-session-2026-11-13/README.md)「压测网络改到单独进程后复测」）。

## 没做的

- 千兆这类比快发速度（每秒 16 MB）还快的线路，第一阵仍要从每秒 4 MB 爬。
- 手机原生库（`agent-net-native`）随原生库重编一起更新。

## 复现

```sh
cd packages/agent-net-core
cargo test --profile sim --workspace
PYTHONIOENCODING=utf-8 python sim/mutants.py 一阵一阵
cp sim/results/2026-11-14-ramp/exp/exp_ramp.rs sim/tests/        # 实验，跑完删掉
AGENT_NET_BULK_MIB=1 AGENT_NET_WINDOW=8192 AGENT_NET_SEND_BUFFER_MIB=24 cargo test --profile sim -p agent-net-sim --test exp_ramp -- --nocapture
cp sim/results/2026-11-14-auto-window/exp/exp_compare.rs sim/tests/
AGENT_NET_POLICY=auto cargo test --profile sim -p agent-net-sim --test exp_compare -- --nocapture
cargo build --release -p agent-net-sim --bin share
SHARE_MODE=full SHARE_TIMER_US=1 ./target/release/share
```
